# 从专家单调性到代数完备:导出新 MR、理论解释、实践重要性

> 动机(作者论点):N5 发现三套生产级核电代码的 110 条专家 MR **全是单调性(O≤)、单块**。
> 本文论证:专家凭经验/直觉推导 MR → 偏向 O≤、单块 → 难以覆盖方程算子代数的全部不变性;
> NOETHER 可**不依赖专家**直接从算子代数导出 MR,覆盖更多块、检出更多故障。

## 2. 理论解释:为什么专家 MR 偏 O≤、单块

- **单调性是经验最易达的块**:工程师靠参数敏感性建立直觉("硼↑→k↓"),这正是 O≤ 块。
  其余块需要识别**结构/代数性质**:对称群(G)、算子自伴(T\*)、守恒律(Conservation)、
  极限/收敛(L\*)、跨方法序(E\*)—— 这些不是"敏感性直觉",需显式算子代数知识。
- **可证伪的选择偏差**:人类 MR 识别系统性欠采样非 O≤ 块;且这一偏差**由块结构可预测**
  (O≤ = "经验可达"块,其余 = "代数潜在"块)。NOETHER 的 CONSTRUCT-MP **演绎枚举全部块**,
  消除该偏差。
- **与 IBT 衔接**:每块 MR 有检测核(盲区)。O≤-only 测试 = 继承 O≤ 核 → 对"只被 G/T\*/
  Conservation 抓"的故障零覆盖(§1 的 12/47)。框架补上的正是这些块的并集检出力。

## 3. 导出的跨块 MR 候选(框架直接产出,专家未列)

> **状态标注(诚实)**:以下为 **framework-derived CANDIDATE MRs**,由各代码的**控制方程算子
> 代数**经 CONSTRUCT-MP 模板导出,**尚未经专家/可执行验证**(专家此前只验证了 O≤ 子集)。
> 每条附**前提**与**块**。要升为 validated 需 §5 材料。

### SACOS(子通道:质量/能量/动量守恒;Fps,Tin,Po,P,Lf,Tm,Kform → To,Rb,Rv,Vf,…)

| # | 块 | 候选 MR | 前提 |
|---|---|---|---|
| D-S1 | **Conservation** | 能量守恒:Σ_i ṁ_i(h_out,i−h_in,i) = P(总焓升=总功率) | 收敛稳态;绝热边界 |
| D-S2 | **Conservation** | 质量守恒:Σ 入口流量 = Σ 出口流量(横流净为 0) | 稳态 |
| D-S3 | **G** | 对称通道布局 + 对称 BC → 输出场在通道置换下等变(permute→permute) | 几何/BC 对称 |
| D-S4 | **L\*** | 轴向节点加密 → To、ΔP 收敛(Richardson 比 ~ 阶数) | 数值收敛 |
| D-S5 | **E\*** | 低含气率极限下 均相 vs 漂移流 模型一致 | 单相/低 quality |

### LOCUST(栅格输运/扩散 k-本征;Tfuel,Burn,Enrich,Boron,… → Keff,Power)

| # | 块 | 候选 MR | 前提 |
|---|---|---|---|
| D-L1 | **Conservation** | 中子平衡:(1/Keff)∫νΣ_f φ = ∫Σ_a φ + 泄漏(平衡残差≈0) | 收敛本征 |
| D-L2 | **T\*** | 源-探测器互易(adjoint flux):D 处源对 S 响应 = S 处源对 D 响应 | 自伴(adjoint)formulation |

### SPARK(堆芯节块扩散/燃耗;CBC,AO,R0,Fq,…)

| # | 块 | 候选 MR | 前提 |
|---|---|---|---|
| D-P1 | **Conservation** | 功率归一:∫power = 总功率;临界搜索不动点:在 CBC 处 k=1 | 收敛 |
| D-P2 | **G** | 1/4 或 1/8 堆芯对称装载 → 功率分布对称、AO/Fq 在对称下不变 | 对称 config |

**观察**:这些候选**全部落在专家漏掉的非 O≤ 块**;其中 **Conservation(D-S1/S2、D-L1、D-P1)
是极强的近精确 oracle**,对安全关键核电代码价值高,却被专家整体留在桌面上。

## 4. 实践重要性(本理论的价值命题)

1. **覆盖**:专家在这些代码上覆盖 **1 块(O≤)**;框架可导出 **5–6 块**(§3 + S12 已示同型域 6 块)。
2. **检出**:由 §1,缺的块带来 **+25.5%** 故障检出(只被非 O≤ 块抓);框架免专家即可补上。
3. **高价值 oracle 被遗漏**:Conservation(质量/能量/中子平衡)、T\*(互易)是最强 oracle 之一,
   专家凭直觉难系统产出;框架从守恒律/自伴性**直接导出**。
4. **去专家依赖**:MR 不再受限于工程师的敏感性直觉与单块习惯;算子代数枚举所有块。

→ 论文 takeaway:**专家 MR 是单块(O≤)、覆盖不全的经验产物;NOETHER 从方程算子代数
演绎导出多块 MR,覆盖率与检出力更高,且不需专家** —— 这是框架在测试实践中的核心价值。

## 5. 推导/验证还需的材料(回答"是否需要补充资料")

**现状**:§3 候选已可**从公开的控制方程 + 变量表导出**(无需更多即可得"候选"层)。
要从 **候选 → 精确 → 可执行验证**(最强,像 S12 用 numpy 那样),按优先级需要:

| 优先 | 材料 | 作用 | 缺它的后果 |
|---|---|---|---|
| P0 | 各代码**控制方程 / 理论手册**(扩散 vs 输运?守恒形式?BC?) | 确认算子代数 → 候选 MR **正确**而非"合理猜测" | 候选可能含物理偏差 |
| P0 | **模型几何/对称性**(1/4 堆芯?组件旋转?通道布局对称?) | G 块前提**精确化** | G 候选只能附"若对称"条件 |
| P1 | **变量语义 + 单位**(Rb 平衡含气率 vs Rv 空泡份额、Pa、Kform…消歧) | 守恒/序关系**精确配平** | 配平式可能错配变量 |
| P1 | **可执行访问 / 样例 I/O**(或一个可跑的简化版) | **可执行验证**候选(像 numpy leg2)→ validated | 候选停留"待验证" |
| P2 | 代码 **V&V / 基准报告** | 引用既有守恒/对称检查、佐证 | 仅自证 |

**最小路径**:仅 P0(控制方程 + 几何)即可把 §3 候选从"合理"升为"正确的、带精确前提的 derived MR";
P1 的可执行访问可进一步把它们**验证**(把本论点从"理论上可导"升为"实测覆盖更高")。
