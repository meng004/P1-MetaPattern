## 0. 执行方式(4 类,全黑盒)

| 类 | 怎么跑 | 适用块 |
|---|---|---|
| **I 单次运行不变量** | 跑 1 个标准算例,**后处理输出**查一个恒等式/残差 | Conservation、临界搜索 |
| **II 两次变换比对(metamorphic)** | 跑 base + 1 个变换后的算例,比对输出关系 | G 对称、T\* 互易、O≤ 单调 |
| **III 加密序列** | 同算例跑网格/能群/节块 N,2N,4N,看收敛 | L\* 极限 |
| **IV 双方法比对** | 同算例跑两种本构/求解器选项 | E\* 方法比较 |

**通过判据**:残差/不对称/不一致 < 容差(见 §4)。**记录**:base 卡、变换、实测值、容差、PASS/FAIL。

## 4. 容差指引 + 回报模板

- **守恒/平衡/临界搜索(V-S1/S2/S3, V-L1/L2, V-P1/P2/P3)**:近精确,容差取**求解器收敛量级**
  (能量/功率 ≤0.5%,质量/反应率 ≤0.1%,k 残差/Keff−1 ≤1e-5)。这些**最该 PASS**,FAIL 即真 bug。
- **对称/互易(V-S4, V-L3/L4, V-P4/P5)**:容差取数值不对称/迭代收敛量级(≤0.1%);注意对称
  算例须几何 + BC 同时对称。
- **极限(V-S5, V-L5, V-P6)**:不要求绝对值,要求**逐次差单调递减**(或 Richardson 比落入阶数带)。
- **方法(V-S6, V-L6, V-P7)**:用各代码**文档基准容差**(SACOS:出口温度/流量 ≤10%、含气率 ≤20%;
  中子学:k ≤ 文档限值);同代码不同关系式应更紧。

**回报模板(每条 MR 一行)**:

```
代码 | MR-ID | 块 | base算例名 | 变换 | 实测残差/差异 | 容差 | PASS/FAIL | 备注
```

回报后我把 `n5_derived_mrs_precise.md` 与论文 §Empirical 的状态从 **EQ-grounded** 升为
**executable-validated**,并把"框架覆盖更高"从方程级升为**实测级**证据。FAIL 项(若有)按 §10.2 /
诚实原则如实记录(可能是真 bug,也可能是前提不满足,需具体分析)。
