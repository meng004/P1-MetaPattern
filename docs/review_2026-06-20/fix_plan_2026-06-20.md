## 1. 总体判断与策略

### 1.1 三轮独立评审已收敛——这是最强信号

| 轮次 | 方式 | 裁决 |

| 06-16 | 6 个隔离 Opus + 网关 5 厂商 | Major（38–72） |
| 06-17 | 5 厂商网关 + 30-agent 对抗验证 | Major（自判 0 存活 blocker） |
| 06-20 | 5 席冷读网关（gpt-5.5 / deepseek-v4-pro 等） | **2 Reject + 3 Major，61/100** |

关键诚实点（与 MEMORY `independent-review-beats-iterative-self-review` 一致）：06-17 那轮"自家对抗验证"判 17/23 是误读、0 blocker，但换成隔离强模型立刻 2 Reject。**"论文已自述某边界" ≠ "该边界不再是退稿理由"**（报告 §6："披露不能替代解决"；CLAUDE.md §10.7）。真实 TOSEM 审稿人更像冷读网关，不会因为你自己声明了就放过。

### 1.2 binding constraint 不是理论，是 presentation 闸门 + 实证 rigor

- 理论：真 delta（IBT、Theorem 1′ 证伪）已存在且非循环，证明已在 `theory/` 与 Appendix C.6；Theorem 1/2 的"平凡"是 **significance** 风险，**纯靠重写 framing 即可化解**，无需补新定理。
- presentation（最低分 ~39）：80 页 ≈ TOSEM 软上限 3 倍，是唯一的 desk-reject 硬闸门（LEN-01）。**纯写作**。
- 实证（最低分 4.1）：自评语料 / LLM-only rater / GenMorph 落败 / 欠功效 pilot——**一部分写作可诚实化，一部分必须真做实验，不能伪装**。

### 1.3 策略：减法 + 诚实分层；先解锁送审，再谈接收率

报告 §6 原话：接收率的关键不在加材料，而在做减法——把稿件从"全景研究档案"改成"一个主张、三条硬证据、一个可复核 artifact"。

本方案据此分三层，并给出**两条路线**：

- **路线 A（尽快送审）**：只做层 0 + 层 1（全 writing/compliance，零新实验）。现实成熟度 → 约 **68–72**，可送审，但大修概率仍高（接收率 ~45–55%）。
- **路线 B（补强后送审）**：层 0 + 层 1 + 层 2（含真实验）。现实成熟度 → 约 **75–78**，进入"值得投、大修概率下降"区间。时间成本数周 + 需招独立人类 rater。

## 3. 诚实红线清单（执行护栏，违反即 §6.4/§10.7 违规）

对抗验证发现以下动作"做"与"做歪"只有一线之隔，执行时必须钉死：

1. **A3 (κ)**：0.931 是 **"LLM-多数投票 vs 作者自标（按 MR 名前缀确定性解析）"**——两侧都不是独立人类。正文必须逐字标注此口径，**禁用"人评/human-pair"简称**；保留 shared-corpus caveat 与"独立人类 κ 作 follow-up"承诺，不得用 0.931 顶替人类 κ。
2. **A9 / A10 / A11 / A12 (压缩与去重)**：GenMorph head-to-head 败局（McNemar p=0.0043、"Set N is dominated by Set G"）是**唯一的负结果披露**。下放 supplement 合法，但**把败局裁决从读者视线移走 = visibility-laundering**。McNemar p=0.0043 + "dominated" 定性结论必须**保留在主文**（哪怕缩成一句）。L1855 box 唯一承载这些定量披露，**不可降为 cross-reference**。
3. **A10 (欠功效)**：DeepCrime n=5 / equivariant n=20 移 supplement 后，正文仍须保留 "underpowered for α=0.05" 标注（§6.9 C6），不得借"移出正文"顺手删 underpowered 自承或软化为 "promising/directional"。
4. **A10 (L\*-blindness headline 化)**：该预测自承 "derivable from public information without consulting any data"（analytic 成分）。提为主证据时必须同步保留这一限定，否则冷读审稿人会把它当作与 Theorem 1 同型的 by-construction 证据，放大而非缓解 significance 风险。
5. **A7 (benchmark 公正性)**：钝直承认占优轴的循环定义性，**不得**软化为 complementarity；这是写作层承认缺口，**不能替代** A16 真实验。
6. **A5 (headline 重定位)**：严格定位为 presentation 修复。**禁止**在 response letter 中将其计为 significance/soundness 的实质回应——claude-opus-4-7 已在"以 IBT 为净贡献"前提下仍判 Reject，重定位买不到 significance 分。
