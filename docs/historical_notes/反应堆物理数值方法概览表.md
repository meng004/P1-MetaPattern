## 反应堆物理数值方法概览表

| ------------------ | --------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 中子输运           | Monte Carlo 粒子输运                    | 几何通用性强，能处理复杂三维结构和精细截面；统计误差可控，接近“参考解”。[spiral.imperial+1](https://spiral.imperial.ac.uk/bitstreams/31b2b230-050e-40d1-9e78-2ff2c94148ec/download) | 计算代价高，收敛慢；与燃耗、热工紧耦合时易出现稳定性与统计噪声问题。[core+1](https://core.ac.uk/download/pdf/334953717.pdf) | 反应堆高精度基准、复杂几何堆芯/实验装置设计与验证。[osti+1](https://www.osti.gov/etdeweb/servlets/purl/20626417) |
| 中子输运           | 离散纵标 SnS_nSn                        | 对各向异性输运描述精确，适合多群输运；在规则网格上效率高，易与热工耦合。[spiral.imperial+1](https://spiral.imperial.ac.uk/bitstreams/31b2b230-050e-40d1-9e78-2ff2c94148ec/download) | 角度离散误差（射线效应）；在高维/细网格下存储与计算量大。[sciencedirect+1](https://www.sciencedirect.com/science/article/abs/pii/S0306454921005351) | 工程输运计算、快堆/先进堆型三维输运分析。                    |
| 中子学（宏观）     | 多群扩散有限差分/有限元                 | 模型简单，方程结构清晰；与线性代数求解器结合成熟，工业经验丰富。[osti+1](https://www.osti.gov/etdeweb/servlets/purl/618634) | 对强各向异性/弱散射体系精度不足；对细节几何需要均匀化近似。[sciencedirect](https://www.sciencedirect.com/topics/engineering/neutron-diffusion-equation) | PWR/BWR 等热堆堆芯功率分布、反应性计算与燃耗分析。           |
| 中子学（堆芯尺度） | Nodal/节块方法                          | 在较粗网格上仍保持较高空间精度，自由度大幅减少，计算效率很高。[sciencedirect](https://www.sciencedirect.com/topics/engineering/neutron-diffusion-equation) | 理论推导复杂，对不规则几何与强局部非均匀性处理不如细网方法直接。[sciencedirect+1](https://www.sciencedirect.com/science/article/abs/pii/S0306454921005351) | 商用堆芯设计代码核心方法，用于三维堆芯稳态与动力学。         |
| 线性代数           | 幂迭代、Krylov 子空间 (GMRES, BiCGSTAB) | 实现简单或收敛加速显著，可用于大型稀疏本征值/线性系统。[intel](https://www.intel.cn/content/dam/www/central-libraries/cn/zh/documents/2023-12/23-cmf157-intel-china-hpc-practice-book-v3-brochure.pdf) | 对预条件依赖强；不良预条件下收敛慢甚至发散。                 | 求解临界谱问题、扩散/输运离散后线性方程组。                  |
| 燃耗/核素演化      | Bateman 链解析解、矩阵指数法            | 对单链或小系统可获得解析或近解析解，精度高；便于误差控制。[repository.cam](https://www.repository.cam.ac.uk/bitstreams/4d539256-9d56-47e4-95e2-e933d0c9edad/download) | 大规模耦合链矩阵指数计算代价大；需要链结构预处理。[repository.cam](https://www.repository.cam.ac.uk/bitstreams/4d539256-9d56-47e4-95e2-e933d0c9edad/download) | 小型系统燃耗、链级燃耗模块、基准算例。                       |
| 燃耗/与中子学耦合  | 预测–校正 (Predictor–Corrector)         | 减弱“通量冻结”误差，燃耗步长可适当放大；耦合更稳定。[repository.cam](https://www.repository.cam.ac.uk/bitstreams/4d539256-9d56-47e4-95e2-e933d0c9edad/download) | 相比简单显式步进多一倍计算量；仍需人工选择步长与容差。       | 工程堆芯燃耗、长周期功率分布和余毒分析。                     |
| 动力学             | 点堆动力学 ODE + Runge–Kutta/隐式法     | 模型与求解器实现简单，适合快速评估全堆功率响应。[osti](https://www.osti.gov/etdeweb/servlets/purl/618634) | 无法给出空间功率分布，只适合整体/近均匀响应分析。            | 控制方程设计、简单瞬态与事故初步分析。                       |
| 动力学（空间依赖） | 扩散/输运 + θ 法、Crank–Nicolson        | 可在保证稳定性的同时保持较高时间精度；适合刚性问题。[oecd-nea](https://www.oecd-nea.org/upload/docs/application/pdf/2019-12/nea4452-crissue-s-vol1.pdf) | 每步需解大规模方程组，计算复杂度高。                         | 重大瞬态、事故分析，三维功率与反馈随时间演化。               |
| 热工水力           | 有限体积法 (FVM)                        | 自然满足守恒，处理对流占优问题稳定性好，适配管道/通道模型。[oecd-nea](https://www.oecd-nea.org/upload/docs/application/pdf/2019-12/nea4452-crissue-s-vol1.pdf) | 在极复杂几何上网格生成和质量控制有难度。                     | 堆芯通道、回路热工分析，两相流模型求解。                     |
| 热工水力           | 一维/多维两相流模型（两流体、漂移通量） | 能描述沸腾、相变、干涸等关键现象，是安全分析关键工具。[oecd-nea](https://www.oecd-nea.org/upload/docs/application/pdf/2019-12/nea4452-crissue-s-vol1.pdf) | 方程高度非线性、刚性强，需稳健隐式求解与大量经验关联。       | DNB、临界热流、LOCA 等安全裕度与事故分析。                   |
| 多物理耦合         | 松耦合迭代 (loose coupling)             | 模块可独立开发，接口清晰，实现和维护成本低。[frontiersin+1](https://www.frontiersin.org/journals/energy-research/articles/10.3389/fenrg.2023.1088718/full) | 对强反馈或快瞬态可能出现收敛慢甚至不稳定，需要小时间步。[oecd-nea](https://www.oecd-nea.org/upload/docs/application/pdf/2019-12/nea4452-crissue-s-vol1.pdf) | 一般稳态/慢瞬态中子–热工、输运–燃耗耦合。                    |
| 多物理耦合         | 紧耦合/强耦合 (tight coupling)          | 在强反馈和快瞬态下更稳定、精度高，可减少迭代次数。[oecd-nea+1](https://www.oecd-nea.org/upload/docs/application/pdf/2019-12/nea4452-crissue-s-vol1.pdf) | 实现复杂，求解器耦合更紧，编程与调试成本高。                 | 严重事故模拟、高反馈系统、多物理强耦合分析。                 |
