# 令蜕变关系集合的完备性定义如下：设待测程序的参数集合为 P，蜕变关系集合为 M={MR1,…,MRn}。定义谓词 Incl(p,MRi) 表示参数 p 在 MRi 中被显式包含（作为输入变换或显式前提固定）并形成可检验输出约束。 若满足 ∀p∈P, ∃MRi∈M 使 Incl(p,MRi) 成立，则称 M 对 P 完备。等价地，令 Si={p∈P | Incl(p,MRi)}，则完备性为 P ⊆ ⋃_{i=1..n} Si。 要求： 1 针对反应堆堆芯计算程序的中子输运功能，列举满足完备性的蜕变关系集合； 2 常用中子输运数值求解方法pn、sn、moc，每种应至少包括一条MR； 3 蜕变关系样式采用Given-when-then，前提条件，适用范围，不适用范围，注意事项； 4 蜕变关系按照物理模型、数值求解算法、实现代码分类； 5 列举参数集合，参数采用中文参数含义_参数符号组成，参数按照物理常数、工况、数值设置、几何拓扑分类； 6 参数与蜕变关系的覆盖矩阵，列为参数，行为蜕变关系，满足完备性Incl(p, MRi)的单元格标注实心原点； 7 生成可下载的完整word文档。

## 物理模型层 MR（示例）

### MR_phys_1：几何对称性与功率镜像

- 分类：物理模型
- Given：
    - 选择具有 1/4 堆芯几何对称性的堆芯模型（堆芯对称性类型_Symmetry = 1/4）。
    - 仅在对称边界上施加理想反射边界条件（边界条件类型_BCtype = 反射）。
    - 其它工况参数（堆芯功率级别_Pcore、控制棒插入深度_Hrod、冷却剂入口温度_Tin 等）保持不变。
- When：
    - 输入一组计算：模型 A 为全芯几何，模型 B 为 1/4 几何配合对称边界；分别用相同输运方法（角离散方法_TypeAng 固定为某一方法，如 PN）求解稳态中子通量与功率分布。
- Then：
    - 1/4 模型在物理对称边界内重构的功率分布，应与全芯结果在对应位置上相符，在给定数值误差容差内保持一致。
- 前提条件：
    - 材料与工况场在几何上严格满足相应对称性。
- 适用范围：
    - 规则格架堆芯，LatticeType 为规则方格或等间距阵列。
- 不适用范围：
    - 存在强非对称源、局部严重缺陷工况。
- 注意事项：
    - 对齐坐标索引，确保比较位置一一对应；数值误差门限需考虑网格、角离散与截面误差。


### MR_phys_2：控制棒插入单调抑制 reactivity

- 分类：物理模型
- Given：
    - 固定核数据集（核数据评价版本_XSver，多群截面温度集_XS_T）。
    - 选取一系列控制棒插入深度_Hrod，满足 Hrod(1) < Hrod(2) < …。
    - 其它工况（堆芯功率级别_Pcore、冷却剂入口温度_Tin、燃料平均温度_Tfuel）固定。
- When：
    - 对每组 Hrod(i) 独立求解稳态中子输运，得到 k_eff(i)。
- Then：
    - k_eff(i) 随控制棒插入深度_Hrod 增大应呈单调不增趋势，允许因数值误差产生微小非严格单调。
- 前提条件：
    - 控制棒材料为吸收体，不改变其它几何和材料布置。
- 适用范围：
    - 远离快临界、无异常反射体配置的常规热堆。
- 不适用范围：
    - 强反馈或特殊设计导致局部增益异常的极端工况。
- 注意事项：
    - 明确“单调不增”的容差，例如允许相邻点间 k_eff 波动不超过若干 pcm。


### MR_phys_3：燃耗阶段 reactivity 下降趋势

- 分类：物理模型
- Given：
    - 固定核数据评价版本_XSver 和燃耗链模型；
    - 选取若干燃耗阶段序号_BurnStep，满足 BurnStep(1) < BurnStep(2) < …；
    - 工况（Pcore、Tin、p_cool）保持额定。
- When：
    - 对每个 BurnStep 求解燃耗中子输运，获得 k_eff(BurnStep)。
- Then：
    - 在典型压水堆工况下，k_eff 随 BurnStep 整体应呈下降或“先升后降但最终下降”的趋势，并在物理预期范围内。
- 前提条件 / 适用范围 / 不适用范围 / 注意事项：类似 MR_phys_2，额外强调燃耗步骤的物理合理性与截面重生成策略一致性。

（MR_phys_4, MR_phys_5 可用于温度反馈、功率峰值与温度场关联等，此处略写骨架。）

## 数值算法层 MR（含 PN / SN / MOC）

### MR_num_PN_1：PN 阶数收敛与角各向异性

- 分类：数值算法（PN）
- Given：
    - 固定能群数_G、空间网格尺寸_hx、工况参数（Pcore、Hrod 等），仅改变角离散方法_TypeAng = PN。
    - 选取一系列球谐阶数 L = L1 < L2 < L3（角阶或方向数_L_or_Ndir）。[^1]
- When：
    - 分别以 L1, L2, L3 阶 PN 求解同一堆芯问题，得到 k_eff(L) 与通量角分布相关积分量。
- Then：
    - k_eff(L) 随 L 提升应趋于收敛，L2 与 L3 结果差异小于 L1 与 L2，通量角各向异性刻画更精细但总体积分量变化受限。
- 前提条件：
    - 问题中角分布不极度尖锐，PN 不发生严重负通量问题。
- 适用范围：
    - 常规反应堆堆芯稳态输运或扩散近似问题。
- 不适用范围：
    - 极强各向异性、强吸收局部问题。
- 注意事项：
    - 明确收敛判据，例如 k_eff 变化小于某阈值。


### MR_num_SN_1：SN 阶数与角网格加密

- 分类：数值算法（SN）
- Given：
    - 角离散方法_TypeAng = SN。
    - 选择一系列方向数 Ndir = N1 < N2 < N3（角阶或方向数_L_or_Ndir）。
    - 其它物理和数值参数固定。
- When：
    - 以 SN_N1, SN_N2, SN_N3 求解中子输运，得到 k_eff(Ndir) 和多个监测位置的群通量。
- Then：
    - 随 Ndir 增大，k_eff 与通量应趋于收敛，N2 与 N3 的差异小于 N1 与 N2；高阶 SN 不应引入新的非物理解。
- 前提条件 / 适用范围 / 不适用范围 / 注意事项：
    - 前提：求积权重与方向集符合标准构造。[^1]
    - 注意事项：检查角分辨率对泄漏计算与强梯度区域的影响。


### MR_num_MOC_1：MOC 射线参数敏感性与收敛

- 分类：数值算法（MOC）
- Given：
    - 角离散方法_TypeAng = MOC，固定能群数_G 与空间网格尺寸_hx。
    - 选取多组特征线设置：MOC特征线数量_Ntrack 与极角/方位角组合，从粗到细（例如 Ntrack_1 < Ntrack_2 < Ntrack_3）。[^6][^7][^5]
- When：
    - 对每组设置求解 MOC 中子输运，获得 k_eff 和关键区域功率分布。
- Then：
    - 随 Ntrack 增大和角度离散加密，k_eff 与选定输出应呈收敛趋势，误差随网格与射线加密减小；过粗射线设置产生的偏差方向应与已知敏感性分析结论一致。[^9][^6]
- 前提条件：
    - 射线覆盖完整，无严重漏射区域。
- 适用范围：
    - 用 MOC 进行高保真堆芯模拟的典型算例（如 C5G7 等）。[^7][^6]
- 不适用范围：
    - 几何极度复杂且未妥善进行射线生成的异常输入。
- 注意事项：
    - 需同时监视计算时间和内存，以避免过度加密导致资源不可接受。


### MR_num_common_1：空间网格收敛性

- 分类：数值算法（通用）
- Given：
    - 固定角离散方法_TypeAng（可为 PN/SN/MOC 之一）和其它参数；
    - 选取空间网格尺寸_hx 的细化序列：hx1 > hx2 > hx3。
- When：
    - 用各 hx 求解同一问题，记录 k_eff 与典型位置的功率密度。
- Then：
    - 随网格加密，输出应呈收敛趋势，粗网格与细网格结果差异逐步减小并落入容差。
- 前提条件 / 适用范围 / 不适用范围 / 注意事项：
    - 前提：数值格式在理论上具有网格收敛性。


### MR_num_common_2：迭代收敛容差与解稳定性

- 分类：数值算法（通用）
- Given：
    - 固定所有物理与网格设置，仅改变迭代收敛容差_eps 和最大内迭代步数_Niter，构造一组 (eps1 > eps2) 且 Niter 足够大。
- When：
    - 对每组 eps 求解，得到 k_eff(eps) 与通量。
- Then：
    - 更严格的 eps2 不应导致发散或完全不同的解分支，且 eps1 与 eps2 的结果差异应小于某预定阈值。
- 前提条件：
    - 固有问题为单一稳定解。

## 实现代码层 MR（示例）

### MR_code_1：不同实现分支的一致性

- 分类：实现代码
- Given：
    - 同一物理问题与数值设置（P 中所有参数固定），仅改变代码实现分支（例如启用/关闭某优化标志）。
- When：
    - 分别运行两种分支得到 k_eff 与功率分布。
- Then：
    - 输出应在数值误差容差内一致，若差异超出阈值则疑似实现错误。
- 前提条件 / 适用范围 / 不适用范围 / 注意事项：
    - 适用：两种分支名义上等价（如只改变并行调度、缓存策略）。[^10][^11][^5]


### MR_code_2：输入参数解析与单位一致性

- 分类：实现代码
- Given：
    - 构造两组输入文件：一组采用“直接值”方式设置堆芯功率级别_Pcore、冷却剂压力_p_cool 等，另一组在不同单位下输入并由代码内部转换（若接口支持）。
- When：
    - 使用两组输入分别运行同一求解器。
- Then：
    - 解析后的内部工况应一致，从而输出 k_eff、功率分布等指标在数值误差容差内一致；若差异明显，则定位为解析/单位转换缺陷。


### MR_code_3：几何与拓扑变换的一致性

- 分类：实现代码
- Given：
    - 使用两种描述几何拓扑方式：一种为显式组件坐标列表，一种为参数化格架（组件布置格架类型_LatticeType 相同）。
- When：
    - 分别构建几何并运行同一物理工况的中子输运求解。
- Then：
    - 输出应等价（k_eff 与主功率分布），差异不超过容差，否则说明几何建模或网格生成实现存在缺陷。

## 参数–MR 覆盖矩阵与完备性

Word 文档中已自动生成一张“参数–蜕变关系覆盖矩阵”表格：

- 行：MR_phys_1…MR_code_3（即蜕变关系集合 M 中的各条 MR）。
- 列：前述 P 中全部参数（XSver…BCtype）。
- 单元格：若某条 MR 的 Given/When 显式包含参数 p，并在 Then 中对其相关输出施加可检验约束，则在该单元格填入“●”，表示 Incl(p, MR) 为真。

矩阵构造满足：

- 每个参数列至少在一行中有“●”，因此形式上满足完备性条件 $P \subseteq \bigcup_i S_i$，其中 $S_i = \{p \in P \mid Incl(p, MR_i)\}$。[^12]
- 在示例文档中通过“贪心分配 + 对 PN/SN/MOC 相关参数的手动强化覆盖”，确保角离散方法_TypeAng、角阶或方向数_L_or_Ndir、MOC特征线数量_Ntrack 等与各自的 PN/SN/MOC MR 显式关联，从而覆盖三种数值方法。

你可以在下载的 Word 文档中：

- 按上面给出的骨架，为每条 MR 填入更具体的物理公式、数值阈值和工程容差；
- 根据实际代码接口，扩展参数集合 P（例如细分截面依赖、更多几何参数），并在覆盖矩阵中增加列；
- 若新增 MR，则在覆盖矩阵新增行，并对相应单元格填入“●”，以保持完备性。
