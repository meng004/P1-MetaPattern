# MR元模式通用性分析报告

## 概述

本报告分析五个元模式（守恒性P1、单调性P2、收敛性P3、轨迹性P4、偏序性P5）在1998—2025年MT文献全域（跨24+应用领域、300—500条MR）上的适用性与通用性，识别无法归类的MR，重新聚类归纳，并分析已有元模式不适用的根本原因。

### 2.2 盲聚类

将上述~30条MR剥离领域标签，仅保留抽象的$(r, R)$结构，按推理策略的相似性聚类。产生两个自然簇：

#### 簇C6：语义一致性（Semantic Consistency）

**成员：** U01, U02, U04, U05, U11, U12, U14

**共同结构：** 输出关系 $R$ 约束的不是两次输出在数值上的等价或偏序，而是在**语义层面**的一致性——事实不矛盾、逻辑蕴含关系保持、实体属性跨上下文一致。

**核心推理策略：** "对输入做语义保持变换后，两次输出的核心**事实/逻辑**应当一致，但表面**形式**可以不同。"

**形式化：**

$$\mathcal{M}_{\text{cons}} = \{(r, R) \mid R(y_1, y_2) \equiv \text{Consistent}(\text{Sem}(y_1), \text{Sem}(y_2))\}$$

其中 $\text{Sem}(\cdot)$ 为语义提取函数，$\text{Consistent}(\cdot, \cdot)$ 为逻辑一致性谓词。

**与P1守恒性的关键差异：**

| 维度 | P1守恒性 | C6语义一致性 |
|------|---------|-----------|
| 输出比较粒度 | 精确相等（$y_1 = y_2$） | 语义一致（$\text{Sem}(y_1) \not\perp \text{Sem}(y_2)$） |
| 容许的输出差异 | 无（或仅浮点容差） | 措辞、格式、表达方式均可不同 |
| 判定方法 | 数值比较 | 需要语义理解（NLI、事实核查） |
| 典型领域 | 科学计算、数值程序 | NLP、LLM、知识系统 |

#### 簇C7：结构保持性（Structural Preservation）

**成员：** U03, U06, U07, U08, U09, U10, U13, U15

**共同结构：** 输入变换 $r$ 具有明确的**代数/逻辑结构**（否定、互补、分解、近似），输出应**保持该结构的代数像**——不是简单的等价或单调，而是按照输入变换的结构规则进行对应变换。

**核心推理策略：** "输入做了结构化变换 $r$（否定、互补、分解），输出应做对应的结构化变换 $R(r)$。"

**形式化：**

$$\mathcal{M}_{\text{struc}} = \{(r, R) \mid R(y_1, y_2) \equiv y_2 = \mathcal{T}_r(y_1)\}$$

其中 $\mathcal{T}_r$ 是由输入变换 $r$ 的结构**诱导**的输出变换。

**子类型：**

| 子类型 | 形式化 | 示例 |
|--------|--------|------|
| 否定反转 | $r$: 插入否定 → $\mathcal{T}_r$: 极性反转 | U03 情感分析 |
| 互补完备 | $r$: 条件C → ¬C → $y_1 \cup y_2 = U$ | U06 Web查询 |
| 分解-重组 | $r$: 分页 → $\bigcup_i y_i = y_{\text{whole}}$ | U15 分页查询 |
| ε-近似不变 | $\|r(x)-x\| < \epsilon$ → $\|y_2-y_1\| < \delta$ | U09 对抗鲁棒性 |
| 等价表达 | $r$: 语义保持重写 → $y_1 = y_2$ | U10 SQL等价 |

**与P1守恒性的关键差异：**

| 维度 | P1守恒性 | C7结构保持性 |
|------|---------|------------|
| 输出变换 | 恒等（$y_2 = y_1$） | 由 $r$ 诱导（$y_2 = \mathcal{T}_r(y_1)$） |
| 输入变换与输出变换的关系 | 独立（$r$ 不影响 $R$ 的形式） | 耦合（$R$ 的形式由 $r$ 决定） |
| 需要的知识 | 知道什么不变 | 知道变换的代数规则 |

### 2.3 新元模式定义

#### P6 语义一致性（Semantic Consistency）

$$\boxed{\mathcal{M}_{\text{cons}}: R(y_1, y_2) \equiv \text{Consistent}(\text{Sem}(y_1), \text{Sem}(y_2))}$$

**推理策略：** "改变提问方式后，回答的核心事实应当不矛盾。"

**适用条件：** 被测程序的输出是**自然语言或结构化知识**，且存在从输出到语义表示的映射 $\text{Sem}(\cdot)$。

**元模式签名条件：** $\text{P6} \in \text{Sig}(P)$ 当且仅当 $P$ 的输出空间 $\mathcal{Y}$ 具有语义层（即输出不仅是数值/符号，还承载事实性内容）。

#### P7 结构保持性（Structural Preservation）

$$\boxed{\mathcal{M}_{\text{struc}}: R(y_1, y_2) \equiv y_2 = \mathcal{T}_r(y_1), \text{ where } \mathcal{T}_r \text{ is induced by } r}$$

**推理策略：** "输入做了结构化变换，输出应做对应的结构化变换。"

**适用条件：** 被测程序的输入变换 $r$ 具有明确的代数/逻辑结构，且存在可推导的输出变换 $\mathcal{T}_r$。

### 2.4 两个新元模式能否归入已有P1—P5？深度辨析

有人可能认为P6只是P1的"松弛版本"，P7只是P1的"推广版本"。以下分析为何它们不能被归入P1：

**P6不是P1的松弛：**

P1的判定方法是**计算性的**——比较两个数值/字符串是否相等。P6的判定方法是**语义性的**——需要自然语言推理（NLI）或事实核查来判定两段文本是否一致。这不是容差阈值的调整（那仍属P1），而是判定方法的本质变化。在科学计算中，P6退化为P1（因为数值输出没有独立于数值之外的"语义层"）；但在NLP领域，P6是不可或缺的独立元模式。

**P7不是P1的推广：**

P1的输出关系是**与输入变换无关的**（无论 $r$ 是什么，输出总是相等）。P7的输出关系由输入变换 $r$ 的结构**决定**（否定→反转，互补→并集完备，分解→子集覆盖）。这种"$r$ 和 $R$ 的耦合"在P1中不存在。P7实际上是一个**函子**（functor）：从输入变换空间到输出变换空间的结构保持映射。

## 第三部分：已有元模式无法适用的原因分析

### 3.1 根本原因：五元模式的隐含假设

五个元模式在设计时带有三个隐含假设，这些假设在科学计算领域成立，但在NLP/Web/ML领域可能被违反：

#### 假设A1：输出空间是度量空间

P1—P5的输出关系 $R$ 依赖于输出空间 $\mathcal{Y}$ 上的**度量结构**：等价（P1）、偏序（P2）、极限（P3）、路径（P4）、距离（P5）。这些概念都预设了 $\mathcal{Y}$ 上的度量 $d(y_1, y_2)$。

科学计算程序的输出是数值向量，天然具备度量结构。但NLP程序的输出是自然语言文本，其"距离"（语义相似度）不具备度量公理的三角不等式性质，且同一个事实可以有无穷多种语言表达。

**当A1被违反时：** 需要P6语义一致性来替代P1的精确等价判定。

#### 假设A2：输入变换与输出关系解耦

P1—P5中，输出关系 $R$ 的**形式**不依赖于输入变换 $r$ 的**具体结构**。例如P2单调性中，无论 $r$ 是增大温度还是增大压力，$R$ 的形式都是"$y_2 > y_1$"。

但在NLP/Web领域，输入变换的语义结构直接决定输出应如何变换：否定→反转，互补→并集，分解→子集。输出关系 $R$ 是 $r$ 的函数。

**当A2被违反时：** 需要P7结构保持性来捕获 $r$ 和 $R$ 的耦合关系。

#### 假设A3：输出判定是算法可判定的

P1—P5的输出关系 $R$ 都是**算法可判定的**：数值比较、偏序检查、极限验证等都可以用有限步骤完成。但P6的一致性判定涉及自然语言理解，从理论上是**图灵不可判定的**（或至少是NP难的），在实践中依赖不完美的NLI模型。

**当A3被违反时：** MR的可操作性从"精确判定"退化为"概率性判定"，引入假阳性和假阴性风险。这并不使MR无效，但改变了其工程使用方式。

### 3.2 领域维度的分析

| 领域 | A1度量空间 | A2解耦 | A3可判定 | P1—P5覆盖率 | 需要P6? | 需要P7? |
|------|----------|--------|---------|------------|---------|---------|
| 科学计算 | ✅ | ✅ | ✅ | ~100% | 否 | 否 |
| 图形学 | ✅ | ✅ | ✅ | ~100% | 否 | 否 |
| 编译器 | ✅ | ⚠️ | ✅ | ~90% | 否 | 部分需要 |
| 数据库/Web | ⚠️ | ❌ | ✅ | ~80% | 否 | 是 |
| ML/分类器 | ⚠️ | ❌ | ✅ | ~85% | 否 | 是 |
| NLP/LLM | ❌ | ❌ | ❌ | ~65% | **是** | **是** |

### 3.3 元模式的"洋葱模型"

上述分析揭示了元模式的**层次结构**——从内核到外层，适用范围递增但精确性递减：

```
┌──────────────────────────────────────────────────┐
│ 第三层：P6语义一致性 + P7结构保持性               │
│   适用域：NLP、LLM、知识系统                      │
│   特征：输出是自然语言，判定需语义理解             │
│                                                  │
│  ┌──────────────────────────────────────────┐    │
│  │ 第二层：P1—P5 五元模式                    │    │
│  │   适用域：科学计算、图形学、编译器、Web    │    │
│  │   特征：输出是数值/符号，判定是算法的      │    │
│  │                                          │    │
│  │  ┌──────────────────────────────────┐    │    │
│  │  │ 第一层：P1守恒性 + P2单调性        │    │    │
│  │  │   适用域：几乎所有程序             │    │    │
│  │  │   特征：最基本的不变性和方向性     │    │    │
│  │  └──────────────────────────────────┘    │    │
│  └──────────────────────────────────────────┘    │
└──────────────────────────────────────────────────┘
```

### 3.4 关键结论

**五元模式P1—P5是"数值计算世界"的完备元模式集。** 在输出空间是度量空间、输入变换与输出关系解耦、输出判定算法可判定的条件下，P1—P5覆盖率接近100%。

**进入"语义计算世界"后，需要P6和P7的扩展。** NLP/LLM领域的MR有约35%无法被P1—P5精确覆盖，根本原因是这些MR的输出关系涉及语义层面的一致性判定（P6）或输入-输出变换的结构耦合（P7）。

**扩展后的七元模式集 {P1, P2, P3, P4, P5, P6, P7} 在1998—2025年全域MR数据上的预期覆盖率 > 97%。**

## 第四部分：七元模式体系总览

| 元模式 | 名称 | 核心推理策略 | 输出空间要求 | 主要适用领域 |
|--------|------|-----------|-----------|-----------|
| P1 | 守恒性 | 什么操作不改变结果？ | 度量空间 | 所有领域 |
| P2 | 单调性 | 增大参数，输出往哪变？ | 偏序空间 | 所有领域 |
| P3 | 收敛性 | 精化/极端化后趋向什么？ | 度量空间 | 数值/科学计算 |
| P4 | 轨迹性 | 响应路径的形态如何？ | 连续空间 | 动力系统/CPS |
| P5 | 偏序性 | 两种方法谁更准？ | 度量空间 | 多算法程序 |
| **P6** | **语义一致性** | **改变表达后事实一致吗？** | **语义空间** | **NLP/LLM/知识系统** |
| **P7** | **结构保持性** | **输入结构变换后输出如何对应变换？** | **代数空间** | **Web/ML/NLP** |

### 4.1 P6/P7与P1的关系

```
P1 守恒性: f(r(x)) = f(x)            ← 输出精确相等
     │
     ├── P6 语义一致性: Sem(f(r(x))) ≈ Sem(f(x))  ← 语义层等价
     │     （P1在语义空间上的推广；当Sem=id时退化为P1）
     │
     └── P7 结构保持性: f(r(x)) = T_r(f(x))       ← 输出按r规则变换
           （P1在非恒等变换群上的推广；当T_r=id时退化为P1）
```

P6和P7都可以视为P1在不同方向上的推广，但推广后产生了P1无法覆盖的独立推理策略。正如实数上的度量无法替代拓扑空间上的连续性概念——后者是前者的推广，但有独立的内容。

### 4.2 对反应堆物理领域的影响

**P6和P7在反应堆物理领域不适用。** 反应堆物理程序的输出是数值向量（核素密度、k_eff、通量分布），不具有独立于数值的语义层（A1成立），输入变换与输出关系解耦（A2成立），判定是算法可判定的（A3成立）。因此：

> **对于反应堆物理软件的蜕变测试，五元模式P1—P5已经完备，无需P6和P7。**

这一结论与此前的分析一致：84条反应堆物理MR全部自然落入P1—P5，27条PWR新增MR同样无一例外。
