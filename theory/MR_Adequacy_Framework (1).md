# 基于参数-元模式交叉矩阵的蜕变关系充分性度量：定义、评价与聚类反向验证

## 摘要

蜕变测试的核心挑战之一是回答"一组蜕变关系够不够"。现有研究缺乏可操作的充分性度量，测试人员无法判断何时停止 MR 识别，也无法系统性地发现 MR 集合的盲区。本文基于元模式体系[综述引用]，提出参数-元模式交叉矩阵（Parameter-MetaPattern Cross Matrix, PMCM）作为 MR 充分性的形式化框架。PMCM 同时衡量跨元模式的覆盖广度和元模式内部的参数覆盖深度，将充分性从二元判断（够/不够）转化为可量化、可定位、可填补的矩阵空白。本文进一步将 PMCM 充分性与基于等价类覆盖的充分性进行对比，证明二者分别在 MR 结构空间和输入值空间两个正交维度上衡量覆盖质量，并定义了融合两个维度的综合二维充分性度量。本文展示了 PMCM 的三重应用价值：（1）评价现有 MR 集合并定位系统性盲区；（2）基于矩阵空白反向验证元模式聚类的合理性；（3）生成 LLM 可执行的二阶段结构化 MR 识别提示词（PMCM 缺口引导推理方向，等价类缺口引导取值范围）。在 HTGR 耦合程序和 LLM 两个案例上的应用表明，PMCM 成功识别了现有 MR 集合中的覆盖缺口，并由缺口推导出新的 MR，验证了框架的实用性。

## 1 引言

### 1.1 问题

给定一组 MR，它"够不够"？这个问题有两个层面：**广度**（MR 是否覆盖了所有应覆盖的结构类型？）和**深度**（在每种结构类型内，MR 是否对所有相关输入参数都有覆盖？）。只有同时满足广度和深度，MR 集合才真正具备充分性。

Li 等在 TOSEM 2025 综述中将 MR 的充分性和多样性列为推荐方向[17]，但现有工作仅有 Zhang 等关于变异评分的初步尝试，缺乏基于 MR 结构特征的度量。

### 1.2 本文贡献

1. 提出参数-元模式交叉矩阵（PMCM），将充分性从"是否覆盖"的二元判断转化为"哪个参数在哪个元模式下未覆盖"的定位工具。
2. 定义综合充分性度量 Adequacy(S, P)，同时惩罚广度缺口和深度缺口。
3. 将 PMCM 充分性与基于等价类覆盖的充分性进行系统对比，证明二者在正交维度上互补，并定义融合两者的综合二维充分性度量 Adequacy_2D。
4. 用 PMCM 反向验证综述中五元模式聚类的合理性——如果某个元模式下的所有参数都已被其他元模式覆盖，则该元模式存在冗余嫌疑。
5. 给出将矩阵空白转化为 LLM 提示词的算法，实现"PMCM 缺口引导推理方向 → 等价类缺口引导取值范围 → MR 自动识别"的闭环。

## 2 形式化定义

### 2.1 基本概念

**定义 1（被测程序的参数结构）。** 设被测程序 P 具有输入参数集 Θ = {θ_1, θ_2, ..., θ_p} 和输出变量集 Y = {y_1, y_2, ..., y_q}。

**定义 2（元模式签名）。** 元模式集合 M = {M_I, M_II, M_III, M_IV, M_V}。程序 P 的**元模式签名** Sig(P) ⊆ M 为 P 的数学规约中理论上应满足的元模式集合。

### 2.2 参数-元模式交叉矩阵

**定义 3（可检查参数集）。** 对于签名中的每个元模式 m ∈ Sig(P)，定义该元模式下的**可检查参数集** Θ_m ⊆ Θ：理论上，变化参数 θ 时程序行为应满足元模式 m 的参数集合。

各元模式的可检查参数判定规则：

| 元模式 | 可检查参数的判定问题 |
|---|---|
| M_I 不变性 | θ 的什么变换不应影响输出？ |
| M_II 单调性 | 增大 θ 时，哪些 y 应单调变化？ |
| M_III 仿射变换 | θ 做线性变换时，y 有可推导的代数关系吗？ |
| M_IV 退化/收敛 | θ 可推向什么极值使 P 退化为简化情形？ |
| M_V 一致性 | θ 的什么语义保持变换下 y 应事实一致？ |

**定义 4（参数-元模式交叉矩阵 PMCM）。** PMCM 是一个 |Θ| × |Sig(P)| 的二维矩阵 C，其中：

> C[θ, m] = |{mr ∈ S : μ(mr) = m ∧ θ ∈ param(mr)}| / max(1, expected(θ, m))

- 若 θ ∉ Θ_m（该参数在该元模式下不可检查），记 C[θ, m] = N/A
- 若 θ ∈ Θ_m 且 C[θ, m] = 0，该单元格为**空白**，代表覆盖缺口
- 若 θ ∈ Θ_m 且 C[θ, m] > 0，该单元格为**已覆盖**

简化版本（二值化）：C[θ, m] = 1（已覆盖）或 0（空白）或 N/A（不适用）。

### 2.3 充分性度量

**定义 5（综合充分性）。**

> Adequacy(S, P) = Σ_{m ∈ Sig(P)} |{θ ∈ Θ_m : C[θ, m] > 0}| / Σ_{m ∈ Sig(P)} |Θ_m|

即所有元模式下已覆盖的参数-元模式对占全部应覆盖对的比例。

**性质：**
- 0 ≤ Adequacy ≤ 1
- Adequacy = 1 当且仅当每个元模式下的每个可检查参数都至少被一条 MR 覆盖
- 若某元模式 m 完全未被覆盖，则其所有 |Θ_m| 个单元格均为 0，对 Adequacy 的贡献为 0——这同时惩罚了广度缺口
- 若某元模式 m 只覆盖了一个参数，则贡献为 1/|Θ_m|——这惩罚了深度缺口

### 2.4 与基于等价类覆盖的充分性的对比

#### 2.4.1 等价类覆盖充分性的定义

在传统软件测试中，等价类划分（equivalence class partitioning）是最基本的测试充分性准则之一。将其迁移到蜕变测试，可以定义另一种 MR 充分性。

**定义 6（输入域等价类划分）。** 设被测程序 P 的输入域为 D，等价类划分 EC = {E_1, E_2, ..., E_n} 是 D 的一个不相交完备覆盖：E_i ∩ E_j = ∅（i ≠ j）且 ∪E_i = D。每个等价类 E_i 内的输入在程序行为上被视为"等价的"——即程序对同一等价类内的输入应有相同的行为模式。

**定义 7（MR 的等价类覆盖充分性）。** 给定 MR 集合 S 和等价类划分 EC，S 对 P 的等价类覆盖充分性定义为：

> Cov_EC(S, P) = |{E_i ∈ EC : ∃ mr_j ∈ S, ∃ (x_s, x_f) ∈ TestPairs(mr_j), x_s ∈ E_i ∨ x_f ∈ E_i}| / |EC|

即被 S 中至少一条 MR 的测试用例对覆盖的等价类数量占全部等价类的比例。

**定义 8（等价类充分性准则）。** S 满足等价类充分性准则当且仅当 Cov_EC(S, P) = 1。

#### 2.4.2 两种充分性的本质差异

PMCM 充分性和等价类充分性分别在两个**正交维度**上衡量 MR 集合的覆盖质量：

| 维度 | PMCM 充分性 (Adequacy) | 等价类充分性 (Cov_EC) |
|---|---|---|
| **覆盖空间** | MR 结构空间（参数 × 元模式） | 输入值空间（等价类） |
| **回答的问题** | "MR 的种类够不够多样？" | "MR 的测试用例够不够广泛？" |
| **度量对象** | MR 本身的结构类型 | MR 驱动的测试用例的输入覆盖 |
| **独立于测试用例？** | 是——只看 MR 的定义 | 否——依赖具体测试用例的选择 |
| **领域知识需求** | 需要确定 Sig(P) 和 Θ_m | 需要确定等价类划分 EC |

关键区别在于：PMCM 衡量的是 MR 集合的**结构多样性**（有没有遗漏某类推理策略），等价类覆盖衡量的是 MR 测试用例的**值域广泛性**（有没有遗漏某个输入子域）。

#### 2.4.3 互补性分析：各自的盲区

**场景 A：PMCM 充分但等价类不充分。** 一组 MR 覆盖了全部五个元模式的所有可检查参数（Adequacy = 1），但每条 MR 的测试用例都集中在输入域的一个狭窄区域。例如，HTGR 程序的单调性 MR 只在功率 [30, 240] MW 范围内验证，但忽略了低功率区 [0, 30] MW——恰恰是 Zhao 等 2026 年发现 32 MW 缺陷的区间[34]。此时 Adequacy = 1 但 Cov_EC < 1，等价类覆盖揭示了 PMCM 未能发现的盲区。

**场景 B：等价类充分但 PMCM 不充分。** 一组 MR 的测试用例覆盖了所有等价类（Cov_EC = 1），但 MR 全部属于单调性元模式——只检查"方向对不对"，从不检查不变性、退化或一致性。此时 Cov_EC = 1 但 Adequacy ≪ 1，PMCM 揭示了等价类覆盖未能发现的结构性盲区。

**场景 C：两者皆不充分的真实案例。** 综述中分析的 191 条 NLP/LLM MR 在等价类维度上覆盖了多种 NLP 任务和输入类型（Cov_EC 较高），但在 PMCM 维度上 M_IV（退化/收敛）几乎完全空白（Adequacy = 0.67）。如果只用等价类充分性评估，会得出"191 条已经很充分"的错误结论；只有叠加 PMCM 评估，才能发现"退化/收敛类推理策略从未被使用"这个系统性遗漏。

#### 2.4.4 综合充分性度量

两种充分性的正交性意味着它们可以被组合为一个更全面的度量：

**定义 9（综合二维充分性）。**

> Adequacy_2D(S, P) = Adequacy(S, P) × Cov_EC(S, P)

- 只有两个因子都接近 1 时，综合充分性才接近 1
- 任一因子为 0 则综合充分性为 0——一个维度的完全缺失无法被另一个维度补偿
- 乘法形式体现了两个维度的独立性：结构多样性和值域广泛性是正交的质量属性

在实践中，更精细的组合方式可以采用加权几何平均：

> Adequacy_2D(S, P) = Adequacy(S, P)^α × Cov_EC(S, P)^(1-α)

其中 α ∈ (0, 1) 反映两个维度的相对重要性。对于安全关键软件（如科学计算程序），结构多样性可能比值域广泛性更重要（α > 0.5），因为遗漏一整类推理策略比遗漏一个输入区间更危险；对于功能密集型软件（如 Web 应用），值域广泛性可能更重要（α < 0.5）。

#### 2.4.5 对 LLM MR 识别的引导意义

两种充分性的区分对 LLM 驱动的 MR 识别有直接的操作意义：

**PMCM 缺口 → LLM 的"推理方向"提示。** 矩阵空白告诉 LLM "该用什么类型的推理策略去找 MR"。例如，空白 (k, M_IV) 生成的提示是："将 few-shot 示例数推向 0 时，系统应退化为什么行为？"LLM 据此推导出 MR_new。

**等价类缺口 → LLM 的"取值范围"提示。** 等价类空白告诉 LLM "已有 MR 的测试用例应在什么输入区间补充"。例如，若 MR 的测试用例只覆盖了功率 [60, 240] MW，等价类分析会提示："请为 [0, 60] MW 低功率区间生成测试用例。"

两类提示可以串联使用：先用 PMCM 发现"需要什么类型的 MR"，再用等价类分析确定"新 MR 的测试用例应覆盖什么取值范围"。这构成了一个完整的"类型→范围"二阶段 LLM 提示流程。

## 3 应用一：对现有 MR 集合的充分性评价

### 3.1 案例 1：HTGR 多尺度耦合程序

**程序参数。** Θ = {稳态功率 P_s, 瞬态功率 P_t, 系统压力 P, 入口流量 Q_m, 入口温度 T_in, 初始温度 T_init}。输出 Y = {固体温度 T_s, 瞬态温度 T_t, 介观温度 T_meso, 微观温差 ΔT_micro, 流体温度 T_f, 压降 D, 出口温度 T_out, 计算时间 Time}。

**签名。** Sig(P) = {M_I, M_II, M_III, M_IV}。

**PMCM（现有 13 条 MR + 1 条性质）：**

| 参数 \ 元模式 | M_I 不变性 | M_II 单调性 | M_III 仿射 | M_IV 退化/收敛 |
|---|---|---|---|---|
| P_s 稳态功率 | **✗ 空白** | ✓ MR1-3 | **✗ 空白** | **✗ 空白** |
| P_t 瞬态功率 | N/A | ✓ Prop4,MR5 | N/A | N/A |
| P 系统压力 | N/A | ✓ MR6 | N/A | **✗ 空白** |
| Q_m 入口流量 | N/A | ✓ MR7-10 | N/A | **✗ 空白** |
| T_in 入口温度 | N/A | ✓ MR11 | N/A | **✗ 空白** |
| T_init 初始温度 | N/A | N/A | N/A | ✓ MR12-14 |

**充分性计算：**
- M_I：Θ_{M_I} = {P_s}（功率对称性？某些工况下功率分布对称变换后温度场应做对应变换）。已覆盖 0/1。
- M_II：Θ_{M_II} = {P_s, P_t, P, Q_m, T_in}。已覆盖 5/5。
- M_III：Θ_{M_III} = {P_s}（线性叠加性？在线性热源假设下，功率加倍→温度场应满足特定代数关系）。已覆盖 0/1。
- M_IV：Θ_{M_IV} = {P_s, P, Q_m, T_in, T_init}。已覆盖 1/5。

Adequacy = (0 + 5 + 0 + 1) / (1 + 5 + 1 + 5) = 6/12 = **0.50**

**诊断：** 充分性仅 50%。主要缺口在 M_I（不变性完全未覆盖）、M_III（仿射变换完全未覆盖）和 M_IV 的深度不足（5 个可检查参数只覆盖了 1 个）。

**由缺口推导的新 MR 候选：**

| 空白单元格 | 推理策略实例化 | 候选 MR |
|---|---|---|
| (P_s, M_IV) | P_s→0 时系统应退化为纯热传导（无内热源） | MR_new1：P_s=0 时，稳态温度应等于入口温度 |
| (P, M_IV) | P→∞ 时，流体密度极大，压降应趋向零 | MR_new2：系统压力极高时，压降应趋近零 |
| (Q_m, M_IV) | Q_m→∞ 时，流体带走所有热量，固体温度→入口温度 | MR_new3：流量极大时，T_s→T_in |

### 3.2 案例 2：LLM（以 GPT-4 为例）

**程序参数。** Θ = {文本内容 x, 文本格式 fmt, few-shot 示例数 k, temperature τ, 上下文长度 ctx, 提示模板 tpl}。

**签名。** Sig(P) = {M_I, M_II, M_IV, M_V}（扩展签名，含退化/收敛）。

**PMCM（基于 191 条 NLP/LLM MR 的结构性评价）：**

| 参数 \ 元模式 | M_I 不变性 | M_II 单调性 | M_IV 退化/收敛 | M_V 一致性 |
|---|---|---|---|---|
| x 文本内容 | ✓ ~95条 | N/A | N/A | ✓ ~40条 |
| fmt 文本格式 | ✓ ~20条 | N/A | N/A | N/A |
| k few-shot数 | N/A | ✓ 若干 | **✗ 空白** | N/A |
| τ temperature | N/A | N/A | **✗ 空白** | ✓ ~16条 |
| ctx 上下文长度 | N/A | ✓ 若干 | **✗ 空白** | N/A |
| tpl 提示模板 | ✓ 若干 | N/A | N/A | N/A |

**充分性计算：**
- M_I：2/2。M_II：2/2。M_IV：0/3。M_V：2/2。

Adequacy = (2 + 2 + 0 + 2) / (2 + 2 + 3 + 2) = 6/9 = **0.67**

**诊断：** M_IV 是系统性盲区。三个空白单元格直接指向三条候选 MR。

**由缺口推导的新 MR：**

> **MR_new4（few-shot 退化）：** k_1 > k_2 > ... > 0 时，perf 单调不增且 k=0 退化为 zero-shot。

> **MR_new5（temperature 退化）：** τ→0 时，输出应退化为贪心解码（确定性最高概率 token）。

> **MR_new6（上下文截断退化）：** ctx→0 时，输出应退化为无上下文的默认回答。

## 4 应用二：反向验证元模式聚类

PMCM 不仅是充分性评价工具，还可以反向检验元模式分类的合理性。核心逻辑是：**如果某个元模式在所有应用场景中都不产生独立的空白单元格（即它的可检查参数总是被其他元模式的 MR 附带覆盖），则该元模式可能是冗余的。**

### 4.1 验证方法

对五个元模式逐一执行以下检验：

**独立空白检验。** 对于元模式 m，检查是否存在至少一个单元格 (θ, m) 满足：（1）C[θ, m] = 0（该单元格在 m 下为空白）；（2）对于所有其他元模式 m'，C[θ, m'] > 0 或 C[θ, m'] = N/A（θ 在其他元模式下要么已覆盖要么不适用）。

如果这样的单元格存在，说明：只有通过 m 的推理策略才能发现 θ 上的这类缺陷——其他元模式无法替代。这为 m 的独立存在提供了充分性评价维度的支撑。

### 4.2 对五个元模式的独立空白检验

**M_I（不变性）独立空白：** 在 HTGR 案例中，(P_s, M_I) 是独立空白——P_s 在 M_II 下已覆盖（方向性），在 M_III 下为空白，在 M_IV 下为空白。但不变性关注的是"什么变换不影响输出"（如功率分布的对称变换），这个问题无法由单调性或退化/收敛的 MR 回答。✓ 通过。

**M_II（单调性）独立空白：** 在 LLM 案例中，(k, M_II) 和 (ctx, M_II) 是独立空白——k 和 ctx 在 M_I 下为 N/A，在 M_V 下为 N/A。只有单调性推理策略能检查"增加 few-shot 示例是否单调提升性能"。✓ 通过。

**M_III（仿射变换）独立空白：** 在 HTGR 案例中，(P_s, M_III) 是独立空白。只有仿射变换推理策略能检查"功率加倍时温度场是否满足线性叠加关系"——单调性只知道方向，不知道比例。✓ 通过。

但在 LLM 案例中，M_III 未出现在签名中（LLM 通常没有精确代数关系）。这说明 M_III 的独立性是**领域依赖的**——在科学计算领域独立，在 LLM 领域不适用。这个发现本身是有价值的：它说明元模式签名的确定需要领域知识，不同领域的签名不同。

**M_IV（退化/收敛）独立空白：** 在 LLM 案例中，(k, M_IV)、(τ, M_IV)、(ctx, M_IV) 都是独立空白——这三个参数在其他元模式下要么已覆盖（k 在 M_II 下有方向性 MR，但退化行为无法由单调性推导）要么为 N/A。只有退化/收敛推理策略能检查"k→0 时退化为 zero-shot"这类性质。✓ 通过。

**M_V（一致性）独立空白：** (x, M_V) 在 PMCM 中是独立的——x（文本内容）在 M_I 下已有大量 MR（同义替换→输出等价），但一致性关注的是"事实不矛盾"而非"输出等价"。如果 LLM 对同义提问给出措辞不同但事实一致的回答，不变性 MR 可能报假阳性（措辞不同→判为失败），而一致性 MR 不会。✓ 通过。

### 4.3 反向验证结论

五个元模式均通过了独立空白检验——每个元模式在至少一个案例中产生了只能由该元模式的推理策略发现的覆盖缺口。这从充分性评价的维度独立支撑了综述中基于推理策略的聚类结果。

关键发现：M_III（仿射变换）的独立性是领域依赖的——在科学计算中不可或缺，在 LLM 中不适用。这支持了综述中"元模式签名 Sig(P) 因领域而异"的设计决策。

## 5 应用三：生成 LLM 可执行的 MR 识别提示词

### 5.1 从矩阵空白到提示词的算法

PMCM 的空白单元格可以被算法化地转换为 LLM 提示词：

```
输入：PMCM 矩阵 C, 被测程序描述 desc(P)
输出：LLM 提示词列表

对每个空白单元格 (θ, m) where C[θ, m] = 0:
    strategy = 元模式 m 的推理策略文本
    question = strategy 中将参数占位符替换为 θ 的描述
    prompt = f"""
    被测系统：{desc(P)}
    参数：{θ} 的取值范围为 {range(θ)}
    
    请回答以下问题：{question}
    
    如果存在这样的性质，请用以下格式描述一条候选 MR：
    - 输入变换：对 {θ} 施加什么操作？
    - 输出关系：输出应满足什么约束？
    - 检错价值：违反该 MR 意味着什么缺陷？
    
    如果不存在，请说明理由。
    """
    yield prompt
```

### 5.2 五个元模式的提示词模板

| 元模式 | 提示词核心问题 |
|---|---|
| M_I | "{θ} 的什么变换（如重排、替换、翻转）不应改变 {y} 的值？" |
| M_II | "增大 {θ} 时，{y} 应该增大、减小、还是不变？为什么？" |
| M_III | "对 {θ} 做线性变换（如加 c 或乘 α）时，{y} 满足什么精确的代数关系？请推导。" |
| M_IV | "将 {θ} 推向极端值 {θ*} 时，系统应退化为什么已知的简化行为？" |
| M_V | "对 {θ} 做语义保持改写后，{y} 的核心事实应保持一致吗？如何检查一致性？" |

### 5.3 与现有方法的对比

| 方法 | MR 来源 | 领域知识需求 | 结构化程度 | 充分性保障 |
|---|---|---|---|---|
| 人工识别 | 专家经验 | 高 | 低 | 无 |
| METRIC/METRIC+ | 输入域划分 | 中 | 中 | 无 |
| MR-Scout | 已有测试用例 | 低 | 低 | 无 |
| GenMorph | 遗传搜索 | 低 | 低 | 无 |
| MARS | 迭代精化 | 中 | 中 | 无 |
| **PMCM + EC + LLM** | **二阶段定向填充** | **低（由 LLM 补充）** | **高** | **有（Adequacy_2D 度量）** |

PMCM 的独特优势在于**有充分性保障**：它不仅能生成 MR，还能量化生成后的 MR 集合是否比生成前更充分——每填充一个空白单元格，Adequacy 值可计算地增加。叠加等价类覆盖后，还能进一步保障新 MR 的测试用例覆盖输入域的所有关键区间。

## 6 HMPA：元模式充分性必要条件假设

基于上述分析，本文提出：

> **HMPA（Hypothesis of Meta-Pattern Adequacy）：** 若 Adequacy(S, P) < 1，则 S 存在可被 PMCM 系统性定位和填补的 MR 结构盲区。

> **HECA（Hypothesis of Equivalence-Class Adequacy）：** 若 Cov_EC(S, P) < 1，则 S 的测试用例存在可被等价类分析系统性定位和填补的输入值域盲区。

> **联合假设：** 若 Adequacy_2D(S, P) < 1，则 S 在结构多样性和/或值域广泛性上存在盲区。

三个假设均为**可证伪的科学假设**而非公理，因为：（1）元模式集合和等价类划分都可能不完备；（2）充分性度量达到 1 不保证缺陷检测率为 100%——只保证在已知分类框架下无系统性遗漏。

HMPA 能否上升为公理，取决于两个条件的证明：元模式集合的完备性（97% 实证覆盖率支撑但不等于证明），以及 Adequacy 与变异评分之间的正相关性（需要大规模实验）。

---

## 7 结论

PMCM 将 MR 充分性从不可操作的定性判断转化为可量化、可定位、可填补、可验证的工程工具。与基于等价类覆盖的充分性相比，PMCM 在正交维度上（MR 结构空间 vs. 输入值空间）提供互补的覆盖质量评估，二者的融合度量 Adequacy_2D 能同时捕获结构多样性缺口和值域广泛性缺口。PMCM 的三重价值已在两个案例中得到验证：评价现有 MR 集合（HTGR Adequacy=0.50, LLM Adequacy=0.67）、反向验证五元模式聚类的合理性（五个元模式均通过独立空白检验）、以及生成 LLM 可执行的二阶段 MR 识别提示词（PMCM 缺口→推理方向，等价类缺口→取值范围）。HMPA 和 HECA 作为可证伪的科学假设，为蜕变测试的充分性理论提供了一个双维度的可操作起点。
