# 压水堆蜕变关系元模式分析报告

## 摘要

本报告以压水堆（PWR）反应堆物理软件为对象，系统完成六项分析任务：（1）给出蜕变关系（MR）元模式的严格数学定义；（2）对已识别的84条MR进行盲聚类，归纳元模式；（3）比较归纳结果与已有五类元模式的语义和数学一致性，给出形式化定义；（4）建立元模式与反应堆物理方程数学结构的映射关系；（5）从ODE/PDE数学结构出发，推导潜在的新元模式；（6）基于新元模式识别新MR。研究表明，五个元模式——守恒性、单调性、收敛性、轨迹性、偏序性——构成反应堆物理MR的充分推理框架，且与方程的对称性、单调算子、逼近理论、动力系统、比较定理五大数学结构存在严格的一一映射。从数学结构推导发现一个候选新元模式"谱结构性"，并由此识别出3条新MR。

## 第一部分：MR元模式的严格数学定义

### 1.1 蜕变关系的形式化定义

**定义1（被测程序）。** 被测程序 $P$ 是一个可计算函数 $P: \mathcal{X} \to \mathcal{Y}$，其中 $\mathcal{X}$ 为输入空间，$\mathcal{Y}$ 为输出空间。

**定义2（蜕变关系）。** 蜕变关系是一个四元组 $\text{MR} = (\mathcal{X}, \mathcal{Y}, r, R)$，其中：

- $r: \mathcal{X} \to \mathcal{X}$ 为**输入变换**（source input → follow-up input）
- $R: \mathcal{Y} \times \mathcal{Y} \to \{true, false\}$ 为**输出关系谓词**

使得对于所有 $x \in \mathcal{X}$，若 $P$ 是正确实现，则：

$$R(P(x),\; P(r(x))) = true$$

更一般地，MR可涉及 $n$ 组输入-输出对：

$$R\bigl(P(x_1), P(x_2), \ldots, P(x_n)\bigr) = true, \quad \text{where } x_i = r_i(x_1)$$

**定义3（MR与性质的区分）。** 一个关于程序行为的命题 $\varphi$ 是**MR**当且仅当它满足：

- 涉及至少两次程序执行的输出之间的关系
- 不需要已知任何单次执行的预期输出（即不依赖测试预言）

仅涉及单次执行输出范围约束的命题（如 $N_i(t) \geq 0$）是**性质**而非MR。需要已知预期值的命题（如 $P(x) = y^*$）是**测试预言**而非MR。

### 1.2 元模式的形式化定义

**定义4（元模式）。** 元模式 $\mathcal{M}$ 是MR的等价类，定义为：

$$\mathcal{M} = \bigl\{\text{MR} = (\mathcal{X}, \mathcal{Y}, r, R) \;\big|\; (r, R) \sim_{\mathcal{M}} (r', R')\bigr\}$$

其中等价关系 $\sim_{\mathcal{M}}$ 基于**推理策略的同构性**：两条MR属于同一元模式，当且仅当测试者在设计它们时问的是同一类结构性问题，且输出关系 $R$ 的逻辑形式同构。

**定义5（元模式签名）。** 给定被测程序 $P$，其**元模式签名** $\text{Sig}(P) \subseteq \{\mathcal{M}_1, \mathcal{M}_2, \ldots, \mathcal{M}_k\}$ 是 $P$ 的数学规约中理论上应满足的元模式集合。签名因领域而异。

**定义6（元模式集合的完备性）。** 元模式集合 $\mathbb{M} = \{\mathcal{M}_1, \ldots, \mathcal{M}_k\}$ 相对于MR集合 $S$ 是**完备的**，当且仅当：

$$\forall \text{MR} \in S, \; \exists \mathcal{M}_i \in \mathbb{M}: \text{MR} \in \mathcal{M}_i$$

即每条MR都可归入某个元模式。

| 维度 | 说明 | 判据 |

## 第三部分：归纳结果与已有五类元模式的对比

### 3.1 语义对比

| 盲聚类簇 | 已有元模式 | 语义一致性 | 判定 |
|----------|-----------|-----------|------|
| C1（不变操作） | P1 守恒性 | 完全一致 | ✅ |
| C2（方向性变化） | P2 单调性 | 完全一致 | ✅ |
| C3（极限/精化） | P3 收敛性 | 完全一致 | ✅ |
| C4（路径形态） | P4 轨迹性 | 完全一致 | ✅ |
| C5（方法偏序） | P5 偏序性 | 完全一致 | ✅ |

**结论：盲聚类的五个簇与已有五个元模式完全一一对应，语义相同，数学内涵一致。**

### 3.2 五个元模式的严格形式化定义

**P1 守恒性（Invariance / Conservation）**

$$\boxed{\mathcal{M}_{\text{inv}} = \{(r, R) \mid R(y_1, y_2) \equiv (y_2 = T \circ y_1) \text{ 其中 } T \in \{\text{id}, \alpha \cdot, +\beta, \text{perm}\}\}}$$

核心结构：输入变换 $r$ 属于程序的**对称群** $G$，输出在群作用下不变或协变。

子类型：

| 子类型 | 形式化 | 示例 |
|--------|--------|------|
| 不变性 | $P(r(x)) = P(x)$ | Bur-Phy-01 步长拆分不变 |
| 线性叠加 | $P(\alpha x_1 + \beta x_2) = \alpha P(x_1) + \beta P(x_2)$ | Bur-Phy-03 初始条件叠加 |
| 因果隔离 | $\pi_i(P(r_j(x))) = \pi_i(P(x))$，$j \notin \text{upstream}(i)$ | Bur-Phy-04 |

**P2 单调性（Monotonicity）**

$$\boxed{\mathcal{M}_{\text{mono}} = \{(r, R) \mid R(y_1, y_2) \equiv (x_1 \leq_{\theta} x_2 \Rightarrow y_1 \leq_{\mathcal{Y}} y_2 \text{ 或 } y_1 \geq_{\mathcal{Y}} y_2)\}}$$

核心结构：输入参数空间上的**偏序**通过程序映射保持或反转到输出空间。

子类型：

| 子类型 | 形式化 | 示例 |
|--------|--------|------|
| 严格单调增 | $\theta_1 < \theta_2 \Rightarrow P(\theta_1) < P(\theta_2)$ | Bol-Phy-12 $\nu\Sigma_f$增→$k$增 |
| 严格单调减 | $\theta_1 < \theta_2 \Rightarrow P(\theta_1) > P(\theta_2)$ | Bol-Phy-11 $\Sigma_a$增→$k$降 |
| 凹/凸性 | $\partial^2 P/\partial\theta^2 \leq 0$ 或 $\geq 0$ | Bur-App-01 $^{239}$Pu密度凹性 |

**P3 收敛性（Convergence / Degeneration）**

$$\boxed{\mathcal{M}_{\text{conv}} = \{(r, R) \mid R(y_1, y_2, \ldots) \equiv \bigl(\theta_n \to \theta^* \Rightarrow P(\theta_n) \to P^*\bigr)\}}$$

核心结构：参数序列趋于极限时，输出趋于已知的**退化解**或**精确解**。

子类型：

| 子类型 | 形式化 | 示例 |
|--------|--------|------|
| 离散化收敛 | $h \to 0 \Rightarrow P_h \to P_{\text{exact}}$ | Dif-Alg-01 节块细化 |
| 退化 | $\theta \to \theta^* \Rightarrow P \to P_{\text{simple}}$ | Bol-App-05 瞬态→稳态 |
| 近似阶数收敛 | $N \to \infty \Rightarrow P_N \to P_{\text{exact}}$ | Bur-Alg-01 CRAM阶数 |

**P4 轨迹性（Trajectory / Path-shape）**

$$\boxed{\mathcal{M}_{\text{traj}} = \{(r, R) \mid R \text{ 约束 } P \text{ 在参数连续域上的路径形态}\}}$$

核心结构：输出作为连续参数（通常是时间或燃耗）的函数，其**路径拓扑**（超调、振荡、极值、S形）受约束。

子类型：

| 子类型 | 形式化 | 示例 |
|--------|--------|------|
| 超调回归 | $\exists t_1 < t_2: P(t_1) > P_\infty, P(t_2) < P(t_1)$ | Bur-Phy-08 碘坑 |
| 先增后降 | $\exists t^*: P'(t) > 0\,(t<t^*),\; P'(t)<0\,(t>t^*)$ | Bur-App-06 $^{238}$Pu停堆后 |
| S形曲线 | 拐点分隔两个单调区间 | Cpl-App-06 Gd自屏蔽 |

**P5 偏序性（Partial-order / Bounding）**

$$\boxed{\mathcal{M}_{\text{pord}} = \{(r, R) \mid R(y_A, y_B) \equiv \bigl(\|y_A - y_{\text{ref}}\| \leq \|y_B - y_{\text{ref}}\| \text{ under condition } C\bigr)\}}$$

核心结构：两种方法/条件产生的近似解之间存在**可证明的精度偏序**。

子类型：

| 子类型 | 形式化 | 示例 |
|--------|--------|------|
| 方法精度偏序 | $\|P_A - P_{\text{ref}}\| \leq \|P_B - P_{\text{ref}}\|$ | Bur-Alg-04 CRAM vs MATREX |
| 条件偏序 | 条件 $C_1$ 下 $P$ 更优 | Cpl-App-08 Gd棒数vs浓度 |
| 偏差定位 | 最大偏差集中于特定子集 | Bol-Alg-04 含氢P₀高估 |

### 3.3 完备性统计

## 第四部分：元模式与反应堆物理方程数学结构的映射

### 4.1 压水堆核心方程的数学结构分析

PWR反应堆物理涉及五层方程，其数学结构可抽象为以下类型：

| 方程 | 数学类型 | 关键算子 | 核心数学结构 |
|------|---------|---------|------------|
| Bateman方程 | 线性常微分方程组 | $\frac{d}{dt} - A(\phi)$ | 矩阵指数半群、线性性、耗散性、因果拓扑 |
| Boltzmann输运方程 | 线性积分-微分方程 | $\hat{\Omega}\cdot\nabla + \Sigma_t - \mathcal{S} - \mathcal{F}/k$ | 自伴随性、正算子、比较原理、Krein-Rutman定理 |
| 中子扩散方程 | 椭圆型PDE本征值问题 | $-\nabla\cdot D\nabla + \Sigma_a - \frac{\nu\Sigma_f}{k}$ | 椭圆正则性、极值原理、Rayleigh商 |
| 共振慢化方程 | Fredholm积分方程 | $\Sigma_t(E)\phi = \int K(E'\to E)\phi\,dE' + S$ | Volterra-Fredholm理论、自屏蔽 |
| 点动力学方程 | 刚性ODE | $\frac{dn}{dt} = \frac{\rho-\beta}{\Lambda}n + \sum\lambda_i c_i$ | 刚性比、特征时间尺度分离 |

### 4.2 元模式—数学结构映射

每个元模式对应方程中一个或多个**可利用的数学结构**。这种对应关系是系统的而非偶然的：

| 元模式 | 对应的数学结构 | 方程中的体现 | 映射机制 |
|--------|-------------|-----------|---------|
| **P1 守恒性** | **对称性与不变量** | 矩阵指数半群 $e^{A(t_1+t_2)}=e^{At_1}e^{At_2}$；解算子线性性 $e^{At}(\alpha N_1+\beta N_2)=\alpha e^{At}N_1+\beta e^{At}N_2$；几何对称群；互易定理 | 方程的**对称群** $G$ 作用下解不变或协变 → 对称变换即为MR的输入变换 $r$，不变性即为输出关系 $R$ |
| **P2 单调性** | **单调算子与比较原理** | 增大 $\Sigma_a$ → $k$ 降（Boltzmann方程的比较原理）；增大 $\nu\Sigma_f$ → $k$ 增；Doppler展宽→自屏蔽增强→$k$降 | 方程的**比较定理**建立参数偏序与解偏序的保持关系 → 参数扰动方向即 $r$，解的方向约束即 $R$ |
| **P3 收敛性** | **逼近理论与退化极限** | 离散化 $h\to 0$ 收敛于连续解；CRAM阶数 $N\to\infty$ 收敛于矩阵指数；退化极限（瞬态→稳态） | 数值方法的**一致性和收敛性**定理 → 精化序列即 $r$，极限解即 $R$ 的参考 |
| **P4 轨迹性** | **动力系统的定性理论** | 碘坑/钐中毒的超调行为（Bateman方程的非对角耦合）；Gd自屏蔽的S形曲线（空间异质燃耗的非线性效应）；控制棒微分价值的余弦分布（扩散方程的本征函数形状） | ODE/PDE解的**定性行为分类**（稳定性、极值、拐点） → 连续参数域上的路径约束即 $R$ |
| **P5 偏序性** | **误差估计与比较定理** | CRAM vs TTA的偏差在闭环核素集中；$P_0$对含氢系统高估 $k$；FDM数值扩散使 $k$ 偏低 | 不同近似方法的**截断误差**之间存在可证明的偏序 → 方法选择即 $r$，精度偏序即 $R$ |

### 4.3 映射的深层逻辑

这五重映射并非孤立存在，而是构成一个**层次结构**：

```
数学方程
  ├── 精确性质 ──→ P1 守恒性（对称性/不变量是方程的精确性质）
  │                P2 单调性（比较原理是方程的精确性质）
  │                P4 轨迹性（定性行为是方程的精确性质）
  │
  └── 近似性质 ──→ P3 收敛性（离散化逼近是数值方法的性质）
                   P5 偏序性（方法比较是数值方法的性质）
```

这意味着：P1、P2、P4源于**物理方程本身**，P3、P5源于**数值求解过程**。这与MR层次分类模型中"物理层MR vs 算法层MR"的划分完全吻合。

## 第五部分：从数学结构推导新元模式的可能性

### 5.1 分析方法

系统检查ODE/PDE理论中尚未被五个元模式覆盖的重要数学结构：

| 数学结构 | 五元模式是否覆盖 | 分析 |
|---------|---------------|------|
| 1. 对称性/不变量 | ✅ P1 | 已覆盖 |
| 2. 比较原理/单调性 | ✅ P2 | 已覆盖 |
| 3. 逼近/收敛定理 | ✅ P3 | 已覆盖 |
| 4. 定性理论（极值/稳定性） | ✅ P4 | 已覆盖 |
| 5. 误差估计/偏序 | ✅ P5 | 已覆盖 |
| 6. **谱结构**（本征值/本征函数） | ⚠️ 部分覆盖 | 需分析 |
| 7. **守恒律/散度定理** | ✅ P1子类 | 已被P1覆盖 |
| 8. **解的正则性** | ✅ P4/P3 | 连续性属轨迹性，精度属收敛性 |
| 9. **Fredholm替代定理** | ✅ P1 | 自伴随互易性属P1 |
| 10. **刚性与时间尺度分离** | ✅ P5 | 方法敏感性属偏序性 |

### 5.2 谱结构性：一个候选新元模式

**数学结构6——谱结构**值得深入分析。Boltzmann方程和扩散方程作为本征值问题，具有丰富的谱性质：

- **Krein-Rutman定理**：正算子的主本征值最大且对应的本征函数处处为正
- **本征值间距**：$k_1 > k_2 > k_3 > \ldots$，间距反映几何/材料特征
- **本征函数正交性**：$\int \phi_m \phi_n^{\dagger} dV = \delta_{mn}$（自伴随情形）
- **优势比** $k_1/k_2$：决定幂迭代收敛速度

**候选元模式 P6 谱结构性（Spectral Structure）：**

$$\mathcal{M}_{\text{spec}} = \{(r, R) \mid R \text{ 约束本征值分布或本征函数形态}\}$$

核心推理策略："改变参数后，本征值谱如何重排？本征函数形态如何变化？"

### 5.3 P6是否真正独立于P1-P5？

逐一检查P6候选MR是否可归入现有元模式：

| 候选MR | 内容 | 最接近的现有元模式 | 能否归入 |
|--------|------|---------------|--------|
| 主本征值正定 | $k_1 > 0$，对应本征函数处处正 | P1（正算子不变量） | ✅ 可归入P1 |
| 优势比随几何增大 | 增大堆芯→$k_1/k_2$增大 | P2（单调性） | ✅ 可归入P2 |
| 高阶模态衰减 | $k_n \to 0$ as $n \to \infty$ | P3（收敛性） | ✅ 可归入P3 |
| **谐波反应性偏序** | 添加反射层：$\Delta k_1 > \Delta k_2 > \Delta k_3$ | P2?  P5? | ⚠️ 模糊 |
| **对称破缺→本征值分裂** | 对称几何扰动→简并本征值分裂 | P4? | ⚠️ 模糊 |
| **本征函数节面数** | 第 $n$ 阶本征函数有 $n-1$ 个节面 | 无直接对应 | ❌ 新结构 |

**结论**：大部分谱性质可归入现有元模式，但"本征函数节面数"和"对称破缺导致的本征值分裂"具有独特的数学结构，难以自然归入P1-P5。然而，这两类MR的**工程可操作性极低**——实际PWR程序通常只计算基态（$k_1$），高阶谐波几乎不作为标准输出。因此：

> **P6谱结构性在数学上有独立性，但在反应堆物理工程实践中不构成独立的可操作元模式。**
>
> **五个元模式P1-P5在PWR反应堆物理领域构成充分且实用的推理框架。**

### 5.4 从其他ODE/PDE结构的系统搜索

为确保完整性，我们进一步分析三类重要数学结构：

**（a）Hamilton结构与辛对称性**

PWR方程均为耗散系统（Bateman方程的特征值实部≤0，输运方程有碰撞项），不具有Hamilton结构。辛对称性不适用于反应堆物理。→ **不产生新元模式。**

**（b）分岔与混沌**

PWR运行工况远离分岔点（负反馈系数确保稳定性）。分岔分析在反应堆动力学理论中有学术意义，但在PWR设计程序验证中不具工程可操作性。→ **不产生工程可操作的新元模式。**

**（c）变分原理与Rayleigh商**

扩散方程的$k_{eff}$可表示为Rayleigh商的极值：

$$k_{eff} = \max_{\phi} \frac{\int \nu\Sigma_f \phi^2 dV}{\int (D|\nabla\phi|^2 + \Sigma_a \phi^2) dV}$$

这意味着**试探函数越接近真实本征函数，Rayleigh商越接近$k_{eff}$**。此性质产生的MR属于**P3收敛性**（试探函数精化→$k$收敛）。→ **可归入P3，不产生新元模式。**

## 第六部分：基于数学结构识别新MR

尽管P6未成为独立的工程元模式，基于第四部分建立的"数学结构→元模式"映射，我们仍可系统地从尚未被利用的数学性质中识别新MR。

### 6.1 识别方法

对PWR五层方程的每个数学结构，检查是否已有MR利用该结构。若未利用，尝试构造新MR并归入P1-P5。

### 6.2 新识别的MR

**MR-New-01：扩散方程的Rayleigh商上界（P3收敛性）**

| 字段 | 内容 |
|------|------|
| 编号 | Dif-Phy-14 |
| 名称 | Rayleigh商上界性 |
| 输入变换 | 同一堆芯问题，用不同初始猜测启动幂迭代 |
| 输出关系 | 所有中间迭代步的 $k^{(n)}$ 应从上方单调递减趋于 $k_{eff}$（Rayleigh商上界性质） |
| 检错价值 | 若 $k^{(n)}$ 在某步从下方跳升超过 $k_{eff}$，说明幂迭代的源更新或归一化有误 |
| 元模式 | P3 收敛性 |
| 平凡性 | 非平凡 |

**MR-New-02：慢化方程的能量守恒（P1守恒性）**

| 字段 | 内容 |
|------|------|
| 编号 | Res-Phy-01 |
| 名称 | 弹性散射能量守恒 |
| 输入变换 | 纯弹性散射介质（$\Sigma_a=0$，无裂变），不同入射能量 |
| 输出关系 | 散射速率 = 入射速率（中子数守恒：$\int \Sigma_s(E)\phi(E)dE = S_0$） |
| 检错价值 | 若散射处理引入或丢失中子（如多群截面插值中的粒子不守恒），守恒被违反 |
| 元模式 | P1 守恒性 |
| 平凡性 | 半平凡 |

**MR-New-03：缓发中子先驱核的刚性响应偏序（P5偏序性）**

| 字段 | 内容 |
|------|------|
| 编号 | Kin-Alg-01 |
| 名称 | 刚性求解器对快瞬态的精度偏序 |
| 输入变换 | 同一阶跃反应性引入问题，用显式Euler vs 隐式求解器 |
| 输出关系 | 大步长下显式Euler的功率峰值误差远大于隐式方法（$\|P_{exp}-P_{ref}\| \gg \|P_{imp}-P_{ref}\|$），但极小步长下两者趋于一致 |
| 检错价值 | 若隐式求解器在大步长下的误差反而大于显式，说明隐式格式的实现有误（如Jacobian矩阵构造错误） |
| 元模式 | P5 偏序性 |
| 平凡性 | 非平凡 |

## 第七部分：综合结论

### 7.1 核心发现

1. **五个元模式的严格数学定义已建立。** 守恒性、单调性、收敛性、轨迹性、偏序性分别对应对称群不变性、偏序保持、极限逼近、路径拓扑约束、精度偏序五种形式化结构。

2. **盲聚类结果与已有分类完全一致。** 84条MR的盲聚类自然产生五个簇，与P1-P5一一对应，无残余MR。

3. **元模式与数学结构存在系统映射。** P1←对称性，P2←比较原理，P3←逼近理论，P4←定性理论，P5←误差估计。其中P1/P2/P4源于物理方程精确性质，P3/P5源于数值方法近似性质。

4. **五元模式在PWR领域构成充分框架。** 系统搜索ODE/PDE理论中的其他数学结构（谱理论、辛结构、分岔、变分原理），唯一具有数学独立性的候选P6（谱结构性）因工程可操作性不足而未被采纳。

5. **基于数学结构映射成功识别3条新MR。** Rayleigh商上界性（P3）、弹性散射能量守恒（P1）、刚性求解器精度偏序（P5），均落入现有元模式框架。

### 7.2 统计总览

| 指标 | 数量 |
|------|------|
| 分析的MR总数 | 84 |
| 元模式数量 | 5 |
| 未归类MR | 0 |
| 数学结构候选 | 10 |
| 新候选元模式 | 1（P6谱结构性，因工程可操作性不足未采纳） |
| 新识别MR | 3 |
| 覆盖的PWR方程层级 | 5（共振处理→组件输运→堆芯扩散→燃耗→动力学） |

### 7.3 工程启示

对于PWR反应堆物理软件的蜕变测试实践，五个元模式提供了一个完整的**MR识别策略指南**：

| 当你想检验…… | 使用元模式 | 典型推理问题 |
|------------|----------|------------|
| 程序是否正确实现了方程的对称性 | P1 守恒性 | "改变核素编排顺序，结果应相同吗？" |
| 参数变化方向是否正确传播 | P2 单调性 | "增大硼浓度，$k_{eff}$应降低吗？" |
| 数值精度是否随离散化精化而改善 | P3 收敛性 | "加密网格后，$k_{eff}$应收敛吗？" |
| 物理响应的时间/空间形态是否合理 | P4 轨迹性 | "停堆后Xe浓度应先升后降吗？" |
| 不同方法的精度排序是否正确 | P5 偏序性 | "CRAM的最大偏差应集中在闭环核素吗？" |
