# 钍基熔盐堆有哪些类型？中国728大力发展的是哪一种类型，简称是什么？它有何特点？对比压水堆。

以上是完整的研究报告，以下是核心要点的快速梳理：

## 钍基熔盐堆（TMSR）主要有两大类型

中国TMSR专项将熔盐堆分为**两条路线**：[^1][^2]

- **固态燃料熔盐堆（TMSR-SF）**：燃料为固体TRISO球形颗粒，熔盐仅充当冷却剂，侧重高温工艺热应用（供热、制氢）[^3]
- **液态燃料熔盐堆（TMSR-LF）**：铀/钍的氟化物直接溶于熔盐，燃料与冷却剂合二为一，侧重钍资源高效利用与闭式循环[^1]


## 728工程大力发展的是 TMSR-LF

728工程（中国核电的起点）最初目标就是研发钍基熔盐堆，1971年曾建成零功率冷态熔盐堆。受限于当时工业水平，后转向压水堆路线（秦山核电站）。2011年中国科学院重启后，大力推进的正是**液态燃料路线**，代表工程简称 **TMSR-LF1**（2MWt液态燃料钍基熔盐实验堆），已于2025年11月在世界上首次实现钍铀核燃料转换。[^4][^5][^6][^7]

## TMSR-LF vs 压水堆（PWR）核心对比

| 维度 | TMSR-LF | 压水堆（PWR） |
| :-- | :-- | :-- |
| 冷却剂/压力 | 高温熔盐，**常压**运行[^8] | 高压水，约155 bar[^9] |
| 固有安全 | 负温度系数+重力排盐，被动停堆[^10][^8] | 主动安全系统为主 |
| 冷却水需求 | **无需大量水**，可建戈壁荒漠[^11] | 需大量冷却水，选址受限[^5] |
| 燃料利用率 | 理论可达60%–80%以上[^5] | 约1%–2%[^5] |
| 换料方式 | **在线添料**，无需停堆[^12] | 定期停堆换料 |
| 技术成熟度 | 实验阶段[^6] | 高度成熟，占全球核电~60%[^13] |

TMSR-LF最根本的突破在于将安全底线从"工程措施"下移到"物理固有特性"——常压运行无爆炸风险，液态燃料无熔堆概念，温度升高反应自动减弱。[^5][^14]
