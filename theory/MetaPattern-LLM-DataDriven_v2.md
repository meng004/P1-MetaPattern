# 元模式启发下的MR识别方法：完整研究方案（v2）

## 核心升级：从"固定模板"到"LLM生成+多技术协同"

### 上一版的关键缺陷

上一版方案中，元模式对输入变换的引导方式是**固定模板**——每个元模式预设了一套确定性的变换规则（如P1→"打乱排列顺序"，P2→"增大参数θ"）。这种方式的问题在于：

1. **模板僵化**：同一元模式在不同物理方程上的输入变换差异极大。P1守恒性在Bateman方程上表现为"核素排列不变"和"初始条件线性叠加"，在Boltzmann方程上表现为"几何镜面翻转"和"源-探测器互易"——这四种变换之间没有表面形式的共性，固定模板无法覆盖。

2. **缺乏语义理解**：模板不理解"为什么"某个变换应该触发某种输出关系。例如，Bur-Phy-04（无关核素因果隔离）之所以是P1-MR，是因为A矩阵的稀疏结构决定了因果链拓扑——这是方程的**语义**，不是形式化模板能捕获的。

3. **遗漏非显然变换**：人工专家识别的84条MR中，许多非平凡MR的输入变换高度创造性（如"停堆后观察242Cm→238Pu的串联衰变"），固定模板根本不会生成这种变换。

### 升级方案：三阶段协同框架（MetaPattern-LLM-DataDriven，简称MLD）

```
┌──────────────────────────────────────────────────────────────────┐
│                    MLD 三阶段协同框架                              │
│                                                                  │
│  阶段0: 程序语义理解（Semantic Comprehension）                      │
│  ┌─────────────────────────────────────────────────────┐         │
│  │  输入: 方程手册、算法文档、参数清单、已知MR（可选）       │         │
│  │  工具: LLM（程序语义解析）                              │         │
│  │  输出: 结构化程序语义描述 SemDesc(P)                     │         │
│  │        + PMCM矩阵（标注适用/不适用/空白）                │         │
│  └─────────────────────────────────────────────────────┘         │
│                          ↓                                       │
│  阶段1: 候选MR输入变换生成（Input Transform Generation）           │
│  ┌─────────────────────────────────────────────────────┐         │
│  │  输入: SemDesc(P), PMCM空白单元格, 元模式提示词模板       │         │
│  │  工具: LLM（结构化推理）                                │         │
│  │  过程: 对每个空白单元格(θ,m)，将元模式策略+程序语义       │         │
│  │        组装为结构化提示词 → LLM生成候选输入变换r           │         │
│  │  输出: 候选输入变换集合 {r₁, r₂, ..., rₖ}                │         │
│  └─────────────────────────────────────────────────────┘         │
│                          ↓                                       │
│  阶段2: 输出关系发现（Output Relation Discovery）                  │
│  ┌─────────────────────────────────────────────────────┐         │
│  │  输入: 候选输入变换, 程序运行输出数据                     │         │
│  │  工具: 按元模式分流 →                                   │         │
│  │    P1/P3 → GEP符号回归（适合发现解析关系）               │         │
│  │    P2/P5 → 统计假设检验（适合判定方向/偏序）              │         │
│  │    P4    → 时序形态分析（适合识别路径结构）               │         │
│  │  输出: 候选MR集合 {(r, R, m)}                           │         │
│  └─────────────────────────────────────────────────────┘         │
│                          ↓                                       │
│  验证: 交叉验证 + 外部基准 + 变异测试                              │
└──────────────────────────────────────────────────────────────────┘
```

## 第一部分：问题1——LLM生成候选输入变换是否效率更高？

### 1.1 对比分析

| 维度 | 固定模板方案 | LLM生成方案 |
|------|-----------|-----------|
| **输入变换的来源** | 预定义的数据变异算子（INC/DEC/MUL/NEG等）+ 元模式模板 | LLM基于程序语义+元模式策略推理生成 |
| **语义理解深度** | 零（模板不理解方程含义） | 深（LLM可解析方程结构、物理约束、参数耦合） |
| **变换的创造性** | 低（受限于预定义算子集） | 高（LLM可生成"停堆后观察串联衰变"等创造性变换） |
| **与元模式的耦合** | 弱（模板与元模式的关联是人工硬编码的） | 强（LLM在提示词中同时接收元模式策略和程序语义） |
| **领域适应性** | 需要为每个领域手工设计模板 | 自动适应（只需更换程序语义描述） |
| **可扩展性** | 每增加一个参数需人工补充模板 | 自动覆盖（LLM对新参数自动推理） |

### 1.2 效率提升的机制分析

LLM生成候选输入变换的效率优势来自**三重信息融合**：

**融合1：元模式策略 × 方程语义。** 元模式提供"问什么"（如P1："什么变换不改变输出？"），方程语义提供"为什么"（如Bateman方程的矩阵指数半群性质e^{A(t₁+t₂)} = e^{At₁}·e^{At₂}）。LLM将二者结合，推理出"将总时间T拆为任意不等步，输出应不变"——这是Bur-Phy-01，一个人工专家需要分析方程性质才能得到的MR。

**融合2：参数耦合 × 元模式交叉。** LLM可以同时处理PMCM矩阵的多个空白单元格，发现参数间的耦合关系。例如，(φ, P2)和(Δt, P3)的交叉分析可能产生Bur-Phy-02（变通量步长敏感性）——这条MR涉及φ和Δt的联合变化，固定模板逐参数处理无法发现。

**融合3：已知MR启发 × 空白定向。** 将训练集中的已知MR作为few-shot示例嵌入提示词，LLM可以学习到"反应堆物理MR的'风格'"，然后对空白单元格进行定向生成。这是PMCM充分性框架（Adequacy Framework）的提示词生成算法的自然延伸。

### 1.3 结构化提示词设计

基于PMCM框架已有的提示词模板体系，升级为三层结构：

```
┌────────────────────────────────────────────────────┐
│ 提示词 = 程序语义层 + 元模式策略层 + 约束层            │
├────────────────────────────────────────────────────┤
│                                                    │
│ [程序语义层]                                        │
│ 被测程序: SCALE/ORIGEN 6.3                          │
│ 求解方程: Bateman方程 dN/dt = A(φ)·N               │
│ 形式解: N(t) = e^{At}·N₀                           │
│ 关键性质:                                           │
│   - A矩阵的半群性质: e^{A(t₁+t₂)} = e^{At₁}·e^{At₂} │
│   - A矩阵对φ的仿射依赖性                             │
│   - A矩阵的稀疏结构（因果链拓扑）                      │
│ 参数: φ(中子通量), Δt(步长), N₀(初始密度), k(CRAM阶数) │
│                                                    │
│ [元模式策略层]                                       │
│ 当前分析单元格: (φ, P1守恒性)                         │
│ P1核心问题: "对参数φ施加什么变换，不应改变输出N(t)？"   │
│ P1推理策略:                                         │
│   - 考察φ的什么表示方式变换不影响解                     │
│   - 考察解算子e^{At}是否具有线性/叠加结构               │
│   - 考察程序是否存在加速选项不改变最终解                  │
│                                                    │
│ [约束层]                                            │
│ 已知的P1-MR（few-shot示例）:                         │
│   - Bur-Phy-01: 恒通量步长拆分不变性                  │
│   - Bur-Phy-05: 核素排列不变性                       │
│ 要求: 生成与上述MR不同的新候选输入变换                   │
│ 输出格式:                                           │
│   - 输入变换r: 对φ施加什么具体操作？                    │
│   - 预期输出关系R: 输出应满足什么约束？                  │
│   - 物理依据: 为什么这个变换应该触发这个关系？             │
│   - 检错价值: 违反此MR意味着什么类型的缺陷？              │
└────────────────────────────────────────────────────┘
```

### 1.4 效率预期

| 指标 | 固定模板 | LLM生成 | 提升机制 |
|------|--------|--------|---------|
| 候选输入变换数/参数 | 2~3种（预定义） | 5~10种（LLM推理） | 语义理解释放创造性 |
| 有物理意义的变换占比 | ~40%（大量无意义组合） | ~75%（LLM过滤无意义变换） | 语义约束 |
| 覆盖的MR层次 | 主要是物理方程层 | 物理+算法+工况三层 | LLM理解多层结构 |
| 非平凡变换占比 | <20% | >40% | 元模式策略引导深层推理 |

**结论：LLM生成方案在效率上显著优于固定模板，核心增益来自语义理解对搜索空间的智能压缩。**

## 第二部分：问题2——不适合符号回归的元模式的三种技术方案

GEP符号回归擅长发现y₂ = f(y₁)形式的解析函数关系，但84条MR中约40%的输出关系不是解析函数，而是方向性约束（P2）、路径形态约束（P4）、或算法精度偏序（P5）。以下推荐三种针对性技术方案：

### 方案A：统计假设检验（Statistical Hypothesis Testing）

**适用元模式：P2单调性、P5偏序性**

**核心思路：** 将MR的输出关系转化为统计假设，用非参数检验判定是否成立。

| 元模式 | 零假设 H₀ | 备择假设 H₁ | 检验方法 |
|--------|---------|---------|---------|
| P2单调性 | y_fup与y_src无系统性大小关系 | sign(y_fup - y_src)与元模式预测方向一致 | Wilcoxon符号秩检验 |
| P5偏序性 | 方法A和方法B的输出无系统偏序 | y_A系统性大于（或小于）y_B | 配对Wilcoxon检验 + Cliff's delta效应量 |

**工作流程：**
```
输入: 由LLM生成的候选输入变换r, 元模式m∈{P2,P5}
1. 生成n组(x_src, x_fup)输入偶对（n≥30）
2. 驱动程序执行，收集(y_src, y_fup)输出偶对
3. 计算差异向量 d_i = y_fup_i - y_src_i
4. 对P2: Wilcoxon符号秩检验 H₀: median(d)=0 vs H₁: median(d)>0（或<0）
   对P5: 配对Wilcoxon检验 + Cliff's delta效应量
5. 若p < α（α=0.01）且效应量|d|>0.33（中等效应），
   → 输出候选MR: (r, "y_fup > y_src", m, p值, 效应量)
6. 使用Bonferroni校正控制多重检验的假阳性率
```

**优势：**
- 天然适合方向性/偏序判定，不需要发现具体函数形式
- 非参数方法对数据分布无假设，适合MC程序的非正态输出
- 效应量提供MR的"强度"信息——弱效应的MR检错价值低
- 统计功效可计算，可以事前确定所需样本量

**不足：**
- 只能判定方向，无法发现精确的函数关系（如"超线性依赖"Bur-Phy-12）
- 对于非线性单调关系（如凹凸性），需要扩展为分段检验
- P5偏序性中"偏差集中在哪些核素"的空间定位能力弱——只知道"A比B准"但不知道"在哪最不准"

**增强措施：** 对P5偏序性，补充逐核素/逐空间位置的差异分析——对每个输出分量分别做配对检验，然后按p值排序定位"最大偏差核素"，实现偏差空间定位。

### 方案B：时序形态分析（Temporal Shape Analysis）

**适用元模式：P4轨迹性**

**核心思路：** 将MR的输出关系定义为时间序列的形态特征（极值点、拐点、渐近行为、单调区间），使用形态匹配算法判定输出时序是否符合预期形态。

**形态特征库（基于84条MR中P4的10条轨迹性MR总结）：**

| 形态代号 | 描述 | 特征向量 | 对应MR示例 |
|---------|------|---------|----------|
| MONO↑ | 严格单调递增 | (0极值, 0拐点, 正斜率) | Bur-App-04 稳定裂变产物累积 |
| MONO↓ | 严格单调递减 | (0极值, 0拐点, 负斜率) | Bur-App-03 ²³⁵U/²³⁸U递减 |
| PEAK | 先增后降（单峰） | (1极大值, 0~2拐点) | Bur-Phy-08 碘坑峰值 |
| VALLEY | 先降后增（单谷） | (1极小值, 0~2拐点) | 碘坑恢复 |
| S-CURVE | S形（先缓后急或先急后缓） | (0极值, 1拐点) | Cpl-App-06 Gd自屏蔽曲线 |
| PLATEAU | 趋于平衡态 | (渐近值存在, 导数→0) | Bur-Phy-07 长时平衡 |

**工作流程：**
```
输入: 由LLM生成的候选时序输入变换r, 形态预测template
1. 驱动程序执行，收集时间/燃耗序列 y(t₁), y(t₂), ..., y(tₙ)
2. 特征提取:
   a. 极值点检测: 一阶导数过零点 + 二阶导数符号
   b. 拐点检测: 二阶导数过零点
   c. 单调区间划分: 一阶导数符号连续区间
   d. 渐近行为: 尾部收敛检测（连续k个点变化率<ε）
3. 形态匹配:
   a. 将提取的特征向量与template库中预期形态比对
   b. 使用DTW（动态时间规整）计算形态相似度
   c. 相似度阈值: DTW_norm < 0.2 → 匹配成功
4. 若匹配成功 → 输出候选MR: (r, template形态, P4, DTW距离)
5. 若不匹配 → 标记为"形态异常"，可能揭示程序缺陷
```

**优势：**
- 直接匹配路径的定性结构，不需要拟合具体函数
- 形态特征是人类可理解的（"先增后降"、"S形"），保持物理可解释性
- 对噪声鲁棒（DTW天然容忍时间轴上的伸缩变形）
- "形态异常"本身就是有价值的缺陷信号——如果程序输出的Gd组件k_inf曲线是线性而非S形，说明空间自屏蔽处理有缺陷

**不足：**
- 形态库的完备性问题：6种模板可能遗漏复杂形态（如多峰、振荡衰减）
- 对极值点位置的定量约束较弱：知道"有一个峰"但不知道"峰应在什么时刻"
- DTW阈值的选择依赖经验

**增强措施：**
- 扩展形态库为可组合的原语：MONO↑ + PEAK + PLATEAU 可组合为"先增→峰值→衰减→平衡"
- LLM辅助生成形态预测：不使用固定形态库，而是让LLM根据物理机制预测"这个核素停堆后应该呈什么形态？"——LLM输出形态描述，算法转化为特征约束

### 方案C：约束逻辑推理与关系代数验证（Constraint Logic & Relational Algebra）

**适用元模式：P5偏序性（空间定位子问题）、P1守恒性（集合/逻辑关系子问题）**

**核心思路：** 对于输出关系涉及集合包含、逻辑蕴含、排列不变等结构性约束的MR，使用形式化约束求解器或关系代数操作来验证。

**适用场景细分：**

| 场景 | MR输出关系形式 | 技术 | 示例 |
|------|-------------|------|------|
| 排列不变 | y(π(x)) = y(x), ∀π∈Sym(n) | 排列枚举 + 精确比较 | Bur-Phy-05 核素排列不变性 |
| 线性叠加 | y(αx₁+βx₂) = αy(x₁)+βy(x₂) | 三次运行 + 代数验证 | Bur-Phy-03 初始条件叠加 |
| 因果隔离 | ∂y_i/∂N_j₀ = 0（j不在i上游） | 扰动分析 + 偏导近似 | Bur-Phy-04 无关核素因果隔离 |
| 偏差定位 | argmax_i |y_A,i - y_B,i| ∈ 预期集合 | 逐分量差异排序 + 集合匹配 | Bur-Alg-04 CRAM-MATREX偏差定位 |
| 退化等价 | lim_{θ→θ*} y_complex = y_simple | 极值计算 + 参考解比对 | 各种P3退化MR |

**工作流程：**
```
输入: 由LLM生成的候选MR, 其中输出关系R为结构性约束
1. 解析R的形式 → 选择验证策略
2. 对"排列不变"类:
   a. 随机生成k个排列π₁...πₖ
   b. 对每个排列驱动程序执行
   c. 验证 max_i|y(π_i(x)) - y(x)| < ε
3. 对"线性叠加"类:
   a. 独立运行Case A(N₀=N₀^A), Case B(N₀=N₀^B), Case C(N₀=αN₀^A+βN₀^B)
   b. 验证 |N_C(t) - αN_A(t) - βN_B(t)| < ε
4. 对"偏差定位"类:
   a. 用两种算法分别运行同一问题
   b. 计算逐核素差异 δ_i = |y_A,i - y_B,i|
   c. 排序δ_i，检查top-k核素是否属于LLM预测的"敏感核素集合"
5. 验证通过 → 输出MR: (r, R, m, 验证通过率)
```

**优势：**
- 精确验证结构性约束，不存在统计检验的Type I/Type II错误
- 对P1守恒性和P5偏序性的"定位"子问题特别有效
- 验证结果是确定性的（通过/不通过），不需要设定统计阈值

**不足：**
- 需要对每种约束类型编写专门的验证逻辑，通用性较差
- 排列枚举对高维问题（>20个核素的排列）计算量爆炸——需要随机抽样
- "容差ε的选择"仍然是经验性的，特别是对MC程序

**增强措施：** 让LLM不仅生成候选MR的输入变换和输出关系，还生成对应的验证代码骨架——LLM输出Python脚本模板，人工审查后自动执行。

### 三种方案的综合对比

| 维度 | 方案A 统计检验 | 方案B 形态分析 | 方案C 约束验证 |
|------|-------------|-------------|-------------|
| 适用元模式 | P2, P5 | P4 | P1, P5(定位), P3(退化) |
| 输出关系形式 | 方向性/偏序 | 时序形态 | 结构性约束 |
| 自动化程度 | 高（标准统计流程） | 中高（需形态库） | 中（需约束解析） |
| 假阳性风险 | 可控（p值+效应量） | 中等（DTW阈值） | 低（精确验证） |
| 对MC噪声的鲁棒性 | 高（非参数检验） | 中（DTW容忍噪声） | 低（需考虑σ） |
| 可解释性 | 高（方向+效应量） | 高（形态可视化） | 高（精确约束） |
| 发现新MR的能力 | 中（只验证方向） | 中高（异常形态=缺陷线索） | 低（只验证已知约束） |

### 3.2 各阶段的元模式-技术映射（最终版）

| 元模式 | 阶段1（输入变换生成） | 阶段2（输出关系发现） | 典型MR示例 |
|--------|-------------------|-------------------|----------|
| **P1守恒性** | LLM推理方程对称性/不变量 → 生成候选变换 | **分流**: 若R̂是解析等式→GEP验证精确系数；若R̂是结构约束→方案C精确验证 | 步长拆分不变性(GEP)、核素排列不变性(方案C)、初始条件线性叠加(方案C) |
| **P2单调性** | LLM推理参数增大的物理效应 → 预测方向 | **方案A**: Wilcoxon检验验证方向+Cliff's delta量化效应 | 通量↑→裂变产物↑、吸收截面↑→k↓ |
| **P3收敛性** | LLM推理离散化参数的精化极限 | **分流**: 若R̂是收敛速率→GEP拟合O(h^p)阶数；若R̂是退化等价→方案C验证 | CRAM阶数收敛(GEP)、无穷介质退化(方案C) |
| **P4轨迹性** | LLM推理时序响应的物理机制 → 预测形态模板 | **方案B**: DTW形态匹配+极值点/拐点检测 | ²³⁸Pu先增后降、Gd S形曲线、碘坑轨迹 |
| **P5偏序性** | LLM推理两种算法的截断误差差异 → 预测偏序方向和敏感区域 | **方案A+C**: Wilcoxon检验偏序方向(A)，逐核素差异排序定位敏感核素(C) | CRAM-MATREX偏差定位、P₀高估含氢k |

### 3.3 GEP在MLD框架中的精确定位

GEP不再是"通用输出模式搜索工具"，而是专门服务于**解析函数关系发现**的子组件：

**GEP适用条件（全部满足才使用GEP）：**
1. LLM预测的输出关系R̂包含未知的定量参数（如"N_fup ≈ c·N_src，c未知"）
2. 输出变量是连续数值（非分类、非集合、非逻辑判断）
3. 输入-输出关系可以用初等函数+四则运算表达

**GEP不适用条件（任一满足则不用GEP）：**
1. R̂是纯方向性约束（"y_fup > y_src"）→ 用方案A
2. R̂是路径形态约束（"先增后降"）→ 用方案B
3. R̂是结构性约束（"排列不变"、"因果隔离"）→ 用方案C
4. 输出包含MC统计噪声且信噪比<3 → 统计检验更可靠

**GEP的元模式约束配置（沿用上一版并优化）：**

| 元模式×场景 | GEP函数集 | 终端集 | 适应度 |
|-----------|---------|--------|--------|
| P1×线性叠加 | {+, -, ×, ÷} | {y_src, y_fup, α, β, 常数} | R²(y_fup, f(y_src)) |
| P1×比例关系 | {×, ÷, abs} | {y_src, y_fup} | 1-|y_fup/y_src - c|/c |
| P3×收敛速率 | {×, ^, log, abs} | {h, y_h, y_ref} | R²(log|y_h-y_ref|, f(log h)) |
| P3×退化比例 | {×, ÷, +, -} | {y_complex, y_simple, θ} | R²(y_complex, f(y_simple, θ)) |

### 3.5 MLD框架的创新点总结

| 创新点 | 与前序工作的区别 | 解决的问题 |
|--------|-------------|----------|
| **元模式作为结构先验** | DDHM/GEP将MR识别视为无约束搜索；MLD将元模式注入搜索的每个环节 | C1输入模式盲目性 |
| **LLM理解程序语义后生成候选变换** | 固定模板不理解方程语义；LLM融合方程结构+元模式策略 | 输入变换的僵化性 |
| **按元模式分流到最适技术** | 上一版试图用GEP统一处理所有元模式；MLD承认GEP能力边界，分流到四种技术 | C2输出关系表达局限 |
| **PMCM闭环迭代** | 现有方法无停止准则；MLD用Adequacy值驱动"识别→评估→再识别"循环 | 何时停止MR识别 |
| **三阶段可追溯** | 纯数据驱动方法无法解释"为什么发现这条MR"；MLD每条MR可追溯到 → 哪个空白单元格 → 哪个元模式策略 → 什么物理依据 | C3物理可解释性 |

### 3.6 方案的局限性与未来方向

**局限1：LLM的幻觉风险。** LLM可能生成物理上不成立的候选输入变换（如"增大裂变截面→k降"）。缓解措施：阶段2的数据驱动验证自然过滤虚假候选；但人工审查仍推荐用于安全关键领域。

**局限2：阶段0的程序语义描述质量。** SemDesc(P)的质量直接决定阶段1的候选质量。对于文档不完善的程序，LLM可能无法提取足够的语义信息。未来方向：结合程序静态分析（如变量依赖图）自动提取部分语义。

**局限3：形态库的完备性（方案B）。** 6种基本形态可能无法覆盖所有P4-MR。未来方向：让LLM动态生成形态预测而非使用固定库，实现"元模式策略 → LLM形态预测 → 算法验证"的全自动链路。

**局限4：跨领域泛化。** MLD框架在反应堆物理上有84条MR的实证基础，但在其他领域（ML、Web、NLP）的有效性需要独立验证。五元模式在NLP领域的覆盖率降至78%，可能需要扩展P6/P7元模式。
